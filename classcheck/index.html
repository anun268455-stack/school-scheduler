📷 ClassCheck — เครื่องมือกล้อง

ข้อมูลทั้งหมดยังอยู่ใน Google Sheet เดิมของคุณ หน้านี้แค่ยืมกล้องให้ใช้ได้
เปิดหน้าสแกนบัตรส่งงาน →
บุ๊กมาร์กหน้านี้ไว้ที่หน้าจอหลักของมือถือจะเปิดได้เร็วที่สุด ไม่ต้องตั้งค่าใหม่ทุกครั้ง

ทำไมต้องมีหน้านี้

แอป ClassCheck เดิมถูก Apps Script วางไว้ในกรอบ iframe ที่ ไม่เปิดสิทธิ์กล้อง เบราว์เซอร์จึงบล็อกการเปิดกล้องทุกครั้ง ไม่ว่าจะเขียนโค้ดอย่างไรก็ตาม หน้านี้วางอยู่บน GitHub Pages ที่ไม่มีกรอบครอบ กล้องจึงทำงานได้จริง แล้วส่งผลการสแกนกลับไปเขียนลงชีตเดิมผ่าน API

ตั้งค่าครั้งแรก (ทำครั้งเดียว)

  1. เปิด Apps Script ของ ClassCheck → กดปุ่ม + ข้างคำว่า "ไฟล์" → Script → ตั้งชื่อ API
  2. วางเนื้อหาไฟล์ API.gs ลงไป → Ctrl+S
  3. Deploy → Manage deployments → ไอคอนดินสอ → Version: New version
  4. ตั้ง Who has access = Anyone ★ ข้อนี้สำคัญที่สุด ถ้าเป็น Only myself หน้านี้จะเรียกไม่ได้
  5. กด Deploy แล้วคัดลอกลิงก์ที่ลงท้ายด้วย /exec
  6. เปิดหน้าสแกน วางลิงก์นั้นลงช่องแรก → เชื่อมต่อ
แก้โค้ดใน Apps Script ทุกครั้งต้องกด Deploy → New version ใหม่ ไม่งั้นลิงก์ /exec จะยังวิ่งโค้ดเวอร์ชันเก่าอยู่

เปิดกล้องไม่ได้ ทำยังไง

ขึ้นว่า "เปิดกล้องไม่ได้: กดอนุญาต..."
แตะไอคอนรูปกุญแจ/กล้องที่แถบที่อยู่เว็บ → อนุญาตกล้อง → รีเฟรช
ไม่ขึ้นอะไรเลย ปุ่มกดแล้วเงียบ
ที่อยู่เว็บต้องเป็น https:// กล้องจะไม่ทำงานบน http
เชื่อมต่อไม่สำเร็จ / ตอบกลับมาเป็นหน้าเว็บ
ยังไม่ได้ตั้ง Who has access = Anyone หรือยังไม่ได้ Deploy เวอร์ชันใหม่หลังวาง API.gs
บาร์โค้ดอ่านไม่ติด
ใช้ QR บนบัตรแทน อ่านง่ายกว่าในที่แสงน้อย หรือพิมพ์รหัส 5 หลักในช่องล่างสุด
