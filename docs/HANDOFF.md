### 3. สิ่งที่ทำต่างจากแผนและสเปก (แผนเงียบหรือผิด — ตัดสินระหว่างทำ)

## เครื่องมือลองกับของจริงในเครื่องพัฒนา (หายไปพร้อมเครื่อง ต้องตั้งใหม่ทุก session)

ของปลอมใน `tests/stubs` จับความผิดของ SQL และของ HTTP จริงไม่ได้ ทั้งชั้นเทอมและงานนี้เจอบั๊กจากจุดนี้ ตั้งของจริงใช้เวลาไม่ถึงห้านาที

```bash
python3 -m venv /tmp/wl-venv && /tmp/wl-venv/bin/pip install fastapi==0.115.0 uvicorn==0.30.6 "psycopg[binary]>=3.1"
# PostgreSQL ไม่ยอมรันด้วย root — ใช้ผู้ใช้ postgres และโฟลเดอร์ที่มันเป็นเจ้าของ
runuser -u postgres -- /usr/lib/postgresql/16/bin/initdb -D /var/lib/postgresql/wl-test -A trust -U postgres
runuser -u postgres -- /usr/lib/postgresql/16/bin/pg_ctl -D /var/lib/postgresql/wl-test -o "-p 54329" -w start
runuser -u postgres -- psql -p 54329 -h 127.0.0.1 -U postgres -c "CREATE DATABASE wltest ENCODING 'UTF8' TEMPLATE template0"
DATABASE_URL=postgresql://postgres@127.0.0.1:54329/wltest PORT=18000 WORKLOAD_SETUP_CODE=<คิดเองยาว 12 ตัวขึ้นไป> /tmp/wl-venv/bin/python mock_api.py
```

ฐานข้อมูลต้องเป็น UTF8 (แบบเดียวกับ Neon) — ถ้าเป็น SQL_ASCII psycopg จะคืนข้อความเป็น bytes แล้วทุก route ของ admin ตอบ 403
หน้าเว็บ: `cd workload && npm ci && VITE_API_URL=http://127.0.0.1:18000 npm run build && npx vite preview --port 4174` แล้วขับด้วย Playwright ที่ติดตั้งมากับเครื่อง

**ฝั่งหน้าเว็บตาราง** ด่านกันเขียนตอนเปิดดูเทอมเก่าติดตั้งไว้ที่ axios **สองตัว** — `frontend/src/api/client.ts`
