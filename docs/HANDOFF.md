```bash
python3 -m venv /tmp/wl-venv && /tmp/wl-venv/bin/pip install fastapi==0.115.0 uvicorn==0.30.6 "psycopg[binary]>=3.1"

runuser -u postgres -- /usr/lib/postgresql/16/bin/pg_ctl -D /var/lib/postgresql/wl-test -o "-p 54329" -w start
runuser -u postgres -- psql -p 54329 -h 127.0.0.1 -U postgres -c "CREATE DATABASE wltest ENCODING 'UTF8' TEMPLATE template0"
DATABASE_URL=postgresql://postgres@127.0.0.1:54329/wltest PORT=18000 WORKLOAD_SETUP_CODE=<คิดเองยาว 12 ตัวขึ้นไป> /tmp/wl-venv/bin/python mock_api.py
```

ฐานข้อมูลต้องเป็น UTF8 (แบบเดียวกับ Neon) · หน้าเว็บ: `cd workload && npm ci && VITE_API_URL=http://127.0.0.1:18000 npm run build && npx vite preview --port 4174`

ปัญหาชื่อครูถูกตัดของขั้นที่ 2 หลุดมาถึงรีวิวทั้งสาขาเพราะเหตุนี้
การแข่งกันของสองคำขอ: เปิด `psql` อีกหน้าต่างแล้ว `BEGIN; SELECT … FOR UPDATE;` ค้างไว้ระหว่างยิง route

## ของจริงในโค้ดที่หาเองใหม่จะเสียเวลา (เลขบรรทัดเลื่อนได้ ใช้ grep ยืนยัน)

| เรื่อง | ที่ไหน |
|---|---|
| ทุกคำขอเขียนผ่านด่านเดียว บวกตัวนับรุ่น ล้างแคช แล้วเซฟสแนปช็อต — ยกเว้น `/api/workload/` | `_bump_revision` ต้นไฟล์ `mock_api.py` |
| ด่านกันเขียนเทอมปิด + ลิสต์ path ที่ยกเว้น | `term_blocks_write` · `TERM_WRITE_SAFE_PATHS` |
| ตัวช่วยฐานข้อมูลของเว็บใหม่ (หนึ่งการเชื่อมต่อต่อหนึ่งคำขอ · 503/500 ไทย) | `_wl_db()` |
| ตรวจว่าใครเรียก | `wl_require_session(request, cur)` · `wl_require_admin(request, cur)` |
| ช่องที่แก้ได้ในรอบ (วิชา คาบ ห้อง แก้ที่หลักสูตรเท่านั้น) | `WL_ROW_FIELDS` · `WL_OPTION_TEACHER_FIELDS` |
| เซิร์ฟเวอร์ยืนยันแถวอัตโนมัติเมื่อคำขอมีช่อง `teacher_id` (แม้ค่าเดิม) — หน้าเว็บจึงต้องส่งเฉพาะช่องที่เปลี่ยน | `wl_apply_teacher_change` · `rowPatch` ใน `round.ts` |
| กล่องยืนยัน `force` ของหน้าหลักสูตรเปิดเพราะคำ "(force)" ในข้อความ 409 (มีตัวทดสอบตรึงแล้ว) | `FORCE_MARK` ใน `curriculum.ts` · `tests/py/wlopen.py` |
| สแนปช็อตเก็บตัวแปรในหน่วยความจำ **ไม่กวาดตาราง SQL** | `_snapshot()` |
| ลบครู → `_purge_teacher` ลบคาบ แผนการสอน ฯลฯ (เหตุผลที่การซิงก์ขั้นที่ 3 ห้ามลบ) | `DELETE /api/teachers/{i}` |
| `PUT /api/teachers/{i}` ใช้ `t.update(body)` · `POST /api/teachers/` ไม่เติมค่าตั้งต้นแต่ `/bulk` เติม (ขั้นที่ 3 ต้องใช้) | `update_teacher` · `create_teacher` · `bulk` |

**ฝั่งหน้าเว็บตาราง** ด่านกันเขียนตอนเปิดดูเทอมเก่าติดตั้งไว้ที่ axios **สองตัว** — `frontend/src/api/client.ts`
และ `api/subClient.ts` (ยังไม่มีตัวทดสอบคุม)
