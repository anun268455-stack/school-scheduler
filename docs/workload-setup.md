# คู่มือตั้งค่าเว็บลงอัตรากำลัง (ทำครั้งเดียวตอนเริ่มใช้)

เขียนให้ครูที่ไม่ใช่โปรแกรมเมอร์ทำตามได้ทีละขั้น · ใช้เวลาประมาณ 20-30 นาที

## 0. ก่อนเริ่ม

- เว็บนี้จะขึ้นให้ใช้จริงก็ต่อเมื่องานนี้ถูกรวมเข้าสาขา `main` ของโปรเจกต์แล้วเท่านั้น (ถ้ายังไม่รวม ลิงก์ข้างล่างจะเปิดไม่ได้หรือเป็นของเก่า)
- ลิงก์เว็บ: https://anun268455-stack.github.io/school-scheduler/workload/
- เว็บนี้คุยกับเซิร์ฟเวอร์และฐานข้อมูลตัวเดียวกับโปรแกรมจัดตารางสอน แต่ **ไม่เขียนตารางสอน** ในขั้นนี้ ใช้แค่เก็บทะเบียนครู ทะเบียนวิชา และรหัสเข้า
- ที่ต้องมี: สิทธิ์เข้าหน้า Render ของบริการ `school-scheduler-api` (บัญชีที่เป็นเจ้าของเซิร์ฟเวอร์)

> **กติกาเรื่องรหัสทุกชนิดในคู่มือนี้:** ห้ามพิมพ์รหัสลงในแชต ห้ามเขียนลงไฟล์ใด ๆ ในโปรเจกต์ (repository) และห้ามถ่ายภาพหน้าจอที่เห็นรหัส
> ค่าที่เขียนในคู่มือนี้ เช่น `ตัวอย่าง-ห้ามใช้จริง-123456` เป็นแค่ตัวอย่างให้ดูรูปแบบ ห้ามเอาไปใช้จริง

## 1. ตั้ง "รหัสตั้งค่า" บน Render

รหัสตั้งค่าคือกุญแจใบแรก ใช้พิสูจน์ว่าคุณเป็นเจ้าของเซิร์ฟเวอร์ตัวจริง ก่อนจะให้ตั้งรหัสผู้ดูแลระบบได้

1. เข้า Render → เลือกบริการ `school-scheduler-api`
2. เมนูซ้าย กด **Environment**
3. กด **Add Environment Variable** แล้วกรอก
   - Key: `WORKLOAD_SETUP_CODE`
   - Value: ข้อความที่คิดเอง **ยาวอย่างน้อย 12 ตัวอักษร** เดาไม่ง่าย (รูปแบบตัวอย่าง: `ตัวอย่าง-ห้ามใช้จริง-123456`)
4. กด **Save Changes** เซิร์ฟเวอร์จะเริ่มใหม่เอง รอสักครู่ (ประมาณ 1-3 นาที) จนสถานะเป็น Live

**ห้ามส่งค่านี้ในแชต และห้ามเขียนลงไฟล์ใน repository** · จดไว้บนกระดาษที่เก็บเองเท่านั้น

## 2. ตั้งรหัสผู้ดูแลระบบ

1. เปิดเว็บ (ลิงก์ข้างบน) ถ้าเซิร์ฟเวอร์เพิ่งตื่นอาจรอครั้งแรกนานถึงหนึ่งนาที
2. จะเห็นปุ่มสีน้ำเงิน **"ตั้งรหัสผู้ดูแลระบบครั้งแรก"** กดเลย
3. กรอก 3 ช่อง
   - **รหัสตั้งค่า (จาก Render):** ค่าที่ตั้งในข้อ 1
   - **รหัสผู้ดูแลระบบใหม่:** รหัสที่จะใช้เข้าเว็บเป็นประจำ อย่างน้อย 6 ตัวอักษร
   - **พิมพ์รหัสผู้ดูแลระบบใหม่ซ้ำ**
4. กด **ตั้งรหัสผู้ดูแลระบบ** → เว็บพากลับหน้าล็อกอิน ให้ใส่รหัสผู้ดูแลระบบที่เพิ่งตั้งเพื่อเข้า
5. **กลับไปที่ Render แล้วลบตัวแปร `WORKLOAD_SETUP_CODE` ทิ้ง** (Environment → กดถังขยะที่แถวนั้น → Save Changes)
   เหตุผล: ใครรู้ค่านี้ก็ตั้งรหัสผู้ดูแลระบบใหม่ทับได้ · ถ้าวันหลังลืมรหัสค่อยใส่กลับมา (ดูข้อ 6)

ถ้าหน้าเว็บขึ้นว่า "รหัสตั้งค่าไม่ถูกต้อง" ให้ตรวจว่าพิมพ์ตรงกับที่ใส่บน Render และรอให้เซิร์ฟเวอร์เริ่มใหม่เสร็จก่อน
ใส่รหัสตั้งค่าผิดเกิน 5 ครั้งต้องรอประมาณสิบนาที

## 3. ดึงรายชื่อครูจากโปรแกรมจัดตารางสอน

1. เข้าเว็บด้วยรหัสผู้ดูแลระบบ → เมนู **ทะเบียนครู**
2. กด **ดึงครูจากโปรแกรมจัดตาราง** เว็บจะบอกก่อนว่าจะสร้างครูใหม่กี่คน (ยังไม่เขียนอะไร)
3. กด **ยืนยันดึงครู** → เว็บบอกผลว่าสร้างใหม่กี่คน มีอยู่แล้วกี่คน
4. **ตรวจว่าครูครบ:** จำนวน "ครูทั้งหมด" ที่หัวรายการต้องเท่ากับจำนวนครูในโปรแกรมจัดตารางสอน
   (ตอนทดลองในเครื่องพัฒนามี 143 คน · ของจริงของโรงเรียนอาจต่างกัน ให้เทียบกับของจริง)
   ถ้าไม่เท่ากัน อย่าเพิ่งทำข้อถัดไป ให้แจ้งผู้ดูแลระบบเครื่อง

กดซ้ำกี่ครั้งก็ไม่สร้างครูซ้ำ

## 4. ตั้งรหัสให้แต่ละกลุ่มสาระ

1. เมนู **รหัสเข้า** จะเห็นแถวผู้ดูแลระบบ และหนึ่งแถวต่อกลุ่มสาระ (ทั้ง 11 กลุ่ม) ทุกกลุ่มเป็น "ยังไม่ได้ตั้ง"
2. แถวของกลุ่มที่ต้องการ กด **ตั้งรหัส** → พิมพ์รหัสที่คิดไว้ (อย่างน้อย 6 ตัวอักษร **ห้ามซ้ำกันข้ามกลุ่ม**) → **บันทึกรหัส**
3. จะมีกล่องสีเขียวแสดงรหัสที่เพิ่งตั้ง **ครั้งเดียวเท่านั้น** กด **คัดลอก** หรือจดไว้ทันที
   ปิดกล่องหรือเปลี่ยนหน้าแล้ว **ดูย้อนไม่ได้** (ระบบไม่เก็บตัวรหัสไว้ให้ดู ถ้าลืมต้องตั้งใหม่)
4. ทำซ้ำกับทุกกลุ่ม แล้วแจกรหัสให้หัวหน้ากลุ่มสาระแต่ละท่านโดยตรง (บอกต่อหน้าหรือส่งข้อความส่วนตัว ไม่โพสต์ในกลุ่ม)

ปุ่มอื่นในหน้านี้
- **ตั้งรหัสใหม่** = เปลี่ยนรหัสของกลุ่มที่ตั้งแล้ว คนที่ใช้รหัสเดิมอยู่จะถูกให้ออกจากระบบทันที
- **ปิด** = ยกเลิกรหัสของกลุ่มนั้นชั่วคราว คนที่ใช้อยู่จะถูกให้ออกจากระบบทันที กด **เปิด** เพื่อให้ใช้ได้อีก (ใช้รหัสเดิม)
- แถวผู้ดูแลระบบไม่มีปุ่มปิด เพราะถ้าปิดแล้วจะไม่มีใครเข้าระบบได้เลย

## 5. แจกรหัส

แจกให้หัวหน้ากลุ่มสาระแต่ละท่าน พร้อมลิงก์เว็บ แล้วบอกท่านว่า รหัสนี้ใช้เข้าได้เฉพาะข้อมูลของกลุ่มสาระตัวเอง

## 6. เรื่องที่ต้องรู้

- **รหัสนี้ป้องกันได้แค่เว็บลงอัตรากำลังเท่านั้น** โปรแกรมจัดตารางสอนยังไม่มีระบบล็อกอิน ใครที่รู้ลิงก์ยังเข้าไปแก้ตารางได้
- หนึ่งครั้งที่ใส่รหัส อยู่ในระบบได้ **12 ชั่วโมง** แล้วต้องใส่ใหม่ · ปิดเบราว์เซอร์หรือปิดแท็บแล้วต้องใส่รหัสใหม่เสมอ
- รหัสกลุ่มสาระเดียวกันใช้พร้อมกันหลายเครื่องได้
- เปลี่ยนหัวหน้ากลุ่มสาระ ให้ **ตั้งรหัสใหม่** หรือ **ปิด** รหัสของกลุ่มนั้นทันที
- พิมพ์รหัสผิดหลายครั้งติดกัน (รวมทุกคนประมาณ 10 ครั้งใน 1 นาที) ระบบจะให้รอประมาณหนึ่งนาทีก่อนลองใหม่
- **ลืมรหัสผู้ดูแลระบบ:** ทำข้อ 1 และ 2 ซ้ำ (ใส่ `WORKLOAD_SETUP_CODE` บน Render ใหม่ แล้วกดลิงก์ **"ลืมรหัสผู้ดูแลระบบ"** ที่หน้าล็อกอิน) เสร็จแล้วลบตัวแปรทิ้งอีกครั้ง
- **ไม่มีปุ่มลบครูหรือวิชา** ถ้าครูย้ายหรือเกษียณ ให้ติ๊ก **"ไม่ปฏิบัติงานแล้ว"** (วิชาใช้ "ไม่เปิดสอนแล้ว")
- **ทะเบียนวิชาเริ่มต้นว่าง** ต้องเพิ่มเองที่เมนู **ทะเบียนวิชา** (ตอนนี้ยังไม่มีปุ่มดึงวิชาจากโปรแกรมจัดตาราง)

## 7. ต้องลองด้วยมือก่อนให้คนในโรงเรียนใช้

ลองจากที่นี่ (เครื่องพัฒนา) ไม่ได้ เพราะเข้าฐานข้อมูลจริงของโรงเรียนไม่ได้ ติ๊กเมื่อทำแล้ว

- [ ] กดดึงครูจาก **สำเนา** ฐานข้อมูลจริง แล้วนับว่าได้ครูเท่ากับที่เว็บตารางมี
- [ ] ขณะกรอกในเว็บใหม่ เปิดเว็บตารางอีกเครื่องค้างไว้ — ตัวเลข `revision` ที่ `/api/state/version` ต้องไม่ขยับเลย และหน้าตารางต้องไม่รีโหลด
- [ ] ปิดเทอมในเว็บตาราง แล้วยืนยันว่าเว็บใหม่ยังกรอกได้
- [ ] ล็อกอินด้วยรหัสกลุ่มสาระเดียวกันสองเครื่องพร้อมกัน ทั้งคู่ต้องใช้งานได้

## 8. ข้อสอบของสเปก (ส่วนที่ 11 ทะเบียนครูและวิชา): ข้อไหนผ่านแล้ว ข้อไหนยังค้าง

ผลด้านล่างได้จากเซิร์ฟเวอร์จริงในเครื่องพัฒนา (ฐานข้อมูลทดลอง ครู 143 คน) เมื่อ 9 พ.ย. 2569 (ค.ศ. 2026-11-09)
**ไม่ได้แทนการลองกับสำเนาฐานข้อมูลจริงของโรงเรียน** (ข้อ 7 ข้างบนยังต้องทำ)

| ข้อ | เรื่อง | สถานะ |
|---|---|---|
| 10ก | แก้ชื่อครูแล้วช่องเงื่อนไขต้องไม่เปลี่ยน | ยังค้าง รอแผนขั้นที่ 3 (ปุ่มส่งเข้าโปรแกรม) |
| 10ข | ครูใหม่จากการอัปเดตมีค่าตั้งต้นของเครื่องครบ | ยังค้าง รอแผนขั้นที่ 3 |
| 10ค | กดอัปเดตสองครั้งต้องไม่สร้างซ้ำ | **ผ่านครึ่งเดียว:** ฝั่งดึงครู กดสองครั้งติดกันได้ "สร้างใหม่ 0 คน" ทั้งสองครั้ง ครูคงที่ 143 คน · ฝั่งไม่สร้างวิชาซ้ำ ยังค้าง รอแผนขั้นที่ 3 |
| 10ง | ครูที่ไม่มีในเว็บใหม่ต้องขึ้นให้อ่านและไม่ถูกลบ | ยังค้าง รอแผนขั้นที่ 3 |
| 10จ | ดึงครูเทียบด้วยรหัส ไม่ใช่ชื่อ | **ผ่านในกรณีที่ผูกกันแล้ว** (ดูหมายเหตุ) |
| 10ฉ | คัดลอกวันแรกครบและทุกแถวมีรหัส | **ผ่าน** ได้ 143 คน เท่ากับโปรแกรมจัดตาราง ทุกแถวมีรหัส และชุดรหัสตรงกันทุกตัว |

หมายเหตุ 10จ: ครูที่ดึงมาแล้วถูกแก้ชื่อในเว็บใหม่เป็นสะกดต่างกัน แล้วกดดึงซ้ำ ไม่ถูกสร้างซ้ำ (ครูยังเป็น 143 คน)
แต่เซิร์ฟเวอร์จับคู่ด้วยเลขที่ผูกไว้กับโปรแกรมจัดตาราง (`sched_id`) **ไม่ได้เทียบด้วยรหัสครูโดยตรง** จึงมีกรณีหนึ่งที่ยังซ้ำได้:
ครูที่พิมพ์เพิ่มเองในเว็บใหม่ด้วยรหัสเดียวกับครูในโปรแกรมจัดตาราง โดยไม่เคยผ่านปุ่มดึงครู จะถูกสร้างซ้ำเมื่อกดดึงครู
ตัวอย่างนี้ลองแล้วเกิดจริง (ครูรหัสเดียวกันสองแถว) — เป็นข้อที่ต้องให้เจ้าของแผนตัดสินว่าจะให้ปุ่มดึงครูผูกด้วยรหัสด้วยหรือไม่ **ก่อนใช้จริง ให้เพิ่มครูเข้าทะเบียนด้วยปุ่มดึงครูเสมอ อย่าพิมพ์เพิ่มครูที่มีในโปรแกรมจัดตารางอยู่แล้ว**
