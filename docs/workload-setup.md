# คู่มือเว็บลงอัตรากำลัง: ตั้งค่าครั้งแรก และลงอัตรากำลังทุกภาคเรียน

เขียนให้ครูที่ไม่ใช่โปรแกรมเมอร์ทำตามได้ทีละขั้น

- **ข้อ 0–6 ตั้งค่าครั้งเดียวตอนเริ่มใช้** (ผู้ดูแลระบบ) · ใช้เวลาประมาณ 20-30 นาที
- **ข้อ 7–11 ทำทุกภาคเรียน**: ผู้ดูแลระบบทำหลักสูตร (ข้อ 7) แล้วเปิดรอบอัตรากำลัง (ข้อ 8) → หัวหน้ากลุ่มสาระใส่ครูและส่ง (ข้อ 9)
  → ผู้ดูแลระบบตรวจผ่าน (ข้อ 8) · ทุกคนดูและพิมพ์สรุปได้ที่หน้าสรุปอัตรากำลัง (ข้อ 10)
  → ตอนขึ้นภาคเรียนใหม่ ผู้ดูแลระบบกด **สร้างเทอมใหม่** ในโปรแกรมจัดตารางสอนแล้วเลือกรอบนี้ (ข้อ 11)
- **ข้อ 11ก ระหว่างภาคเรียน**: ผู้ดูแลระบบกด **อัปเดตแผนจากรอบอัตรากำลัง** ในโปรแกรมจัดตารางสอน แล้วติ๊กรับทีละข้อ —
  รอบที่ปิดแล้วของภาคเรียนนี้ใช้ได้เลย · ถ้าอัตรากำลังเปลี่ยนกลางเทอม (ครูย้าย ลาออก เพิ่ม/ลดคาบ) จึงเปิดรอบให้แก้กลางเทอม → แก้ → ปิดรอบ
  (หรือทุกกลุ่มส่งและตรวจผ่าน) → แล้วค่อยกดอัปเดต
- ข้อ 12–16 คือข้อความผิดปกติ เรื่องที่ต้องรู้ และรายการที่ต้องลองด้วยมือก่อนใช้จริง

## 0. ก่อนเริ่ม

- เว็บนี้จะขึ้นให้ใช้จริงก็ต่อเมื่องานนี้ถูกรวมเข้าสาขา `main` ของโปรเจกต์แล้วเท่านั้น (ถ้ายังไม่รวม ลิงก์ข้างล่างจะเปิดไม่ได้หรือเป็นของเก่า)
- ลิงก์เว็บ: https://anun268455-stack.github.io/school-scheduler/workload/
- เว็บนี้คุยกับเซิร์ฟเวอร์และฐานข้อมูลตัวเดียวกับโปรแกรมจัดตารางสอน แต่ **ไม่เขียนตารางสอน** ในขั้นนี้
  ใช้เก็บทะเบียนครู ทะเบียนวิชา รหัสเข้า หลักสูตรของแต่ละภาคเรียน และรอบอัตรากำลัง (ครูคนไหนสอนวิชาไหน ห้องไหน) ·
  การส่งอัตรากำลังเข้าโปรแกรมจัดตารางทำที่ปุ่ม **สร้างเทอมใหม่** ของโปรแกรมจัดตารางสอน ภาคเรียนละครั้ง (ข้อ 11)
  และระหว่างภาคเรียนที่ปุ่ม **อัปเดตแผนจากรอบอัตรากำลัง** (ข้อ 11ก — เขียนเฉพาะข้อที่ติ๊ก ไม่แตะคาบที่ลงไว้)
- ที่ต้องมี: สิทธิ์เข้าหน้า Render ของบริการ `school-scheduler` (บัญชีที่เป็นเจ้าของเซิร์ฟเวอร์)

> **กติกาเรื่องรหัสทุกชนิดในคู่มือนี้:** ห้ามพิมพ์รหัสลงในแชต ห้ามเขียนลงไฟล์ใด ๆ ในโปรเจกต์ (repository) และห้ามถ่ายภาพหน้าจอที่เห็นรหัส
> คู่มือนี้ไม่มีรหัสตัวอย่างให้คัดลอก ทุกรหัสต้องคิดขึ้นเอง

## 1. ตั้ง "รหัสตั้งค่า" บน Render

> **⚠ คำเตือนเรื่องการเริ่มเซิร์ฟเวอร์ใหม่ (ใช้กับทุกจุดในคู่มือนี้ที่ให้กด Save Changes หรือ Manual Deploy บน Render)**
> เซิร์ฟเวอร์ `school-scheduler` เป็นตัวเดียวกับที่ **โปรแกรมจัดตารางสอน** ใช้อยู่ทุกวัน
> ทุกครั้งที่กด Save Changes หรือ Manual Deploy เซิร์ฟเวอร์จะเริ่มใหม่ และระหว่างนั้น 1-3 นาที **ครูจะใช้โปรแกรมจัดตารางสอนไม่ได้**
> **ให้ทำตอนที่ไม่มีใครกำลังจัดตาราง** (เช่น หลังเลิกงาน) และบอกคนที่จัดตารางให้รู้ก่อน

รหัสตั้งค่าคือกุญแจใบแรก ใช้พิสูจน์ว่าคุณเป็นเจ้าของเซิร์ฟเวอร์ตัวจริง ก่อนจะให้ตั้งรหัสผู้ดูแลระบบได้

1. เข้า Render → เลือกบริการ `school-scheduler`
2. เมนูซ้าย กด **Environment**
3. กด **Add Environment Variable** แล้วกรอก
   - Key: `WORKLOAD_SETUP_CODE`
   - Value: ข้อความที่คิดเอง **ยาวอย่างน้อย 12 ตัวอักษร** เดาไม่ง่าย (คิดวลีของตัวเองที่ยาวอย่างน้อย 12 ตัวอักษร ผสมตัวอักษรกับตัวเลข และไม่ใช้คำที่เขียนไว้ในคู่มือนี้)
4. กด **Save Changes** (ดูคำเตือนข้างบน: โปรแกรมจัดตารางจะใช้ไม่ได้ระหว่างนี้) เซิร์ฟเวอร์จะเริ่มใหม่เอง รอสักครู่ (ประมาณ 1-3 นาที) จนสถานะเป็น Live

**ห้ามส่งค่านี้ในแชต และห้ามเขียนลงไฟล์ใน repository** · จดไว้บนกระดาษที่เก็บเองเท่านั้น

## 2. ตั้งรหัสผู้ดูแลระบบ

1. เปิดเว็บ (ลิงก์ข้างบน) ถ้าเซิร์ฟเวอร์เพิ่งตื่นอาจรอครั้งแรกนานถึงหนึ่งนาที
2. จะเห็นปุ่มสีเขียวเข้ม **"ตั้งรหัสผู้ดูแลระบบครั้งแรก"** กดเลย
3. กรอก 3 ช่อง
   - **รหัสตั้งค่า (จาก Render):** ค่าที่ตั้งในข้อ 1
   - **รหัสผู้ดูแลระบบใหม่:** รหัสที่จะใช้เข้าเว็บเป็นประจำ
   - **พิมพ์รหัสผู้ดูแลระบบใหม่ซ้ำ**

   **วิธีตั้งรหัสให้เดายาก:** ระบบบังคับแค่ 6 ตัวอักษร แต่ควรยาว **8 ตัวอักษรขึ้นไป** ผสมตัวอักษรกับตัวเลข
   และไม่ใช้ชื่อกลุ่มสาระ ปี พ.ศ. หรือเลขห้อง (คนอื่นเดาได้ง่าย)
4. กด **ตั้งรหัสผู้ดูแลระบบ** → เว็บพากลับหน้าล็อกอิน ให้ใส่รหัสผู้ดูแลระบบที่เพิ่งตั้งเพื่อเข้า
5. **กลับไปที่ Render แล้วลบตัวแปร `WORKLOAD_SETUP_CODE` ทิ้ง** (Environment → กดถังขยะที่แถวนั้น → Save Changes · โปรแกรมจัดตารางจะใช้ไม่ได้ 1-3 นาที ดูคำเตือนในข้อ 1)
   เหตุผล: ใครรู้ค่านี้ก็ตั้งรหัสผู้ดูแลระบบใหม่ทับได้ · ถ้าวันหลังลืมรหัสค่อยใส่กลับมา (ดูหัวข้อ "ลืมรหัสผู้ดูแลระบบ" ในข้อ 13)

ถ้าหน้าเว็บขึ้นว่า "รหัสตั้งค่าไม่ถูกต้อง" ให้ตรวจว่าพิมพ์ตรงกับที่ใส่บน Render และรอให้เซิร์ฟเวอร์เริ่มใหม่เสร็จก่อน
ใส่รหัสตั้งค่าผิดเกิน 5 ครั้งต้องรอประมาณสิบนาที

## 3. ดึงรายชื่อครูจากโปรแกรมจัดตารางสอน

1. เข้าเว็บด้วยรหัสผู้ดูแลระบบ → เมนู **ทะเบียนครู**
2. กด **ดึงครูจากโปรแกรมจัดตาราง** เว็บจะบอกก่อนว่าจะสร้างครูใหม่กี่คน (ยังไม่เขียนอะไร)
3. กด **ยืนยันดึงครู** → เว็บบอกผลว่าสร้างใหม่กี่คน มีอยู่แล้วกี่คน
4. **ตรวจว่าครูครบ:** จำนวน "ครูทั้งหมด" ที่หัวรายการต้องเท่ากับจำนวนครูในโปรแกรมจัดตารางสอน
   (ตอนทดลองในเครื่องพัฒนามี 143 คน · ของจริงของโรงเรียนอาจต่างกัน ให้เทียบกับของจริง)
   ถ้าไม่เท่ากัน อย่าเพิ่งทำข้อถัดไป ให้แจ้งผู้ดูแลระบบเครื่อง

กดซ้ำกี่ครั้งก็ไม่สร้างครูซ้ำ

**ข้อควรระวัง: ดึงครูก่อน แล้วค่อยพิมพ์เพิ่มเอง**
ปุ่มดึงครูจับคู่ด้วยเลขครูของโปรแกรมจัดตารางที่เว็บนี้จำไว้ในแต่ละแถว ไม่เดาจากชื่อหรือจากรหัสประจำตัว (เช่น T001) โดยตั้งใจ
เพราะชื่อสะกดต่างกันได้ และรหัสประจำตัวที่พิมพ์เองอาจว่างหรือซ้ำ · ผลคือครูที่พิมพ์เพิ่มเองในเว็บนี้ ทั้งที่มีอยู่ในโปรแกรมจัดตารางแล้ว จะกลายเป็นสองแถวหลังกดดึงครู
กติกา: **ดึงครูก่อนเสมอ พิมพ์เพิ่มเองเฉพาะครูที่ยังไม่มีในโปรแกรมจัดตาราง**
ถ้าซ้ำไปแล้ว: ติ๊ก **"ไม่ปฏิบัติงานแล้ว"** ที่แถวที่พิมพ์เอง (แถวที่มีป้าย "ยังไม่เคยส่งเข้าโปรแกรม") และเก็บแถวที่ดึงมาไว้

## 4. ดึงรายชื่อวิชาจากโปรแกรมจัดตารางสอน

1. เมนู **ทะเบียนวิชา**
2. กด **ดึงวิชาจากโปรแกรมจัดตาราง** เว็บจะบอกก่อนว่าจะสร้างวิชาใหม่กี่วิชา (ยังไม่เขียนอะไร)
3. กด **ยืนยันดึงวิชา** → เว็บบอกผลว่าสร้างใหม่กี่วิชา มีอยู่แล้วกี่วิชา
4. **ตรวจว่าวิชาครบ:** จำนวน "วิชาทั้งหมด" ที่หัวรายการต้องเท่ากับจำนวนวิชาในโปรแกรมจัดตารางสอน
   (ตอนทดลองในเครื่องพัฒนามี 271 วิชา · ของจริงของโรงเรียนอาจต่างกัน ให้เทียบกับของจริง)
   ถ้าไม่เท่ากัน อย่าเพิ่งทำข้อถัดไป ให้แจ้งผู้ดูแลระบบเครื่อง

กดซ้ำกี่ครั้งก็ไม่สร้างวิชาซ้ำ · ปุ่มนี้คัดลอกเฉพาะรหัสวิชา ชื่อ ประเภท กลุ่มสาระ คาบคู่ กิจกรรม วิชาเสรี และสถานะเปิดสอน
ไม่คัดลอกห้องเรียนหรือเงื่อนไขการจัดคาบ (ของพวกนั้นยังอยู่ในโปรแกรมจัดตารางตามเดิม)

**ข้อควรระวัง: ดึงวิชาก่อน แล้วค่อยพิมพ์เพิ่มเอง** (เหตุผลเดียวกับครูในข้อ 3)
ปุ่มดึงวิชาจับคู่ด้วยเลขวิชาของโปรแกรมจัดตารางเท่านั้น ไม่เทียบชื่อวิชาหรือรหัสวิชา · วิชาที่พิมพ์เพิ่มเองทั้งที่มีในโปรแกรมจัดตารางแล้ว จะกลายเป็นสองแถวหลังกดดึงวิชา
กติกา: **ดึงวิชาก่อนเสมอ พิมพ์เพิ่มเองเฉพาะวิชาที่ยังไม่มีในโปรแกรมจัดตาราง**
ถ้าซ้ำไปแล้ว: ติ๊ก **"ไม่เปิดสอนแล้ว"** ที่แถวที่พิมพ์เอง (แถวที่มีป้าย "ยังไม่เคยส่งเข้าโปรแกรม") และเก็บแถวที่ดึงมาไว้

## 5. ตั้งรหัสให้แต่ละกลุ่มสาระ

1. เมนู **รหัสเข้า** จะเห็นแถวผู้ดูแลระบบ และหนึ่งแถวต่อกลุ่มสาระ (ปัจจุบัน 11 กลุ่ม) ทุกกลุ่มเป็น "ยังไม่ได้ตั้ง"
2. แถวของกลุ่มที่ต้องการ กด **ตั้งรหัส** → พิมพ์รหัสที่คิดไว้ (**ห้ามซ้ำกันข้ามกลุ่ม**) → **บันทึกรหัส**
   ตั้งให้เดายากแบบเดียวกับรหัสผู้ดูแลระบบ: ยาว 8 ตัวอักษรขึ้นไป ผสมตัวอักษรกับตัวเลข ไม่ใช้ชื่อกลุ่มสาระ ปี พ.ศ. หรือเลขห้อง (ระบบบังคับแค่ 6 ตัว)
3. จะมีกล่องสีเขียวแสดงรหัสที่เพิ่งตั้ง **ครั้งเดียวเท่านั้น** กด **คัดลอก** หรือจดไว้ทันที
   ปิดกล่องหรือเปลี่ยนหน้าแล้ว **ดูย้อนไม่ได้** (ระบบไม่เก็บตัวรหัสไว้ให้ดู ถ้าลืมต้องตั้งใหม่)
4. ทำซ้ำกับทุกกลุ่ม แล้วแจกรหัสให้หัวหน้ากลุ่มสาระแต่ละท่านโดยตรง (บอกต่อหน้าหรือส่งข้อความส่วนตัว ไม่โพสต์ในกลุ่ม)

ปุ่มอื่นในหน้านี้
- **ตั้งรหัสใหม่** = เปลี่ยนรหัสของกลุ่มที่ตั้งแล้ว คนที่ใช้รหัสเดิมอยู่จะถูกให้ออกจากระบบทันที · ถ้าแถวนั้น "ปิดอยู่" การตั้งรหัสใหม่ **ไม่ได้เปิดให้** ต้องกด **เปิด** อีกครั้งจึงจะใช้ได้
- **ปิด** = ยกเลิกรหัสของกลุ่มนั้นชั่วคราว คนที่ใช้อยู่จะถูกให้ออกจากระบบทันที กด **เปิด** เพื่อให้ใช้ได้อีก (ใช้รหัสเดิม)
- แถวผู้ดูแลระบบไม่มีปุ่มปิด เพราะถ้าปิดแล้วจะไม่มีใครเข้าระบบได้เลย

## 6. แจกรหัส

แจกให้หัวหน้ากลุ่มสาระแต่ละท่าน พร้อมลิงก์เว็บ และบอกให้อ่านข้อ 9 (สำหรับหัวหน้ากลุ่มสาระ) กับข้อ 10 (หน้าสรุป)

หัวหน้ากลุ่มสาระที่ใส่รหัสเข้ามาจะเห็นสามเมนู
- **หลักสูตร** — หลักสูตรของทั้งโรงเรียน เปิดดูได้อย่างเดียว (แก้ได้เฉพาะผู้ดูแลระบบ)
- **อัตรากำลังของกลุ่ม** — หน้าที่หัวหน้าใส่ครู · ก่อนผู้ดูแลระบบเปิดรอบให้กลุ่มสาระกรอก (ข้อ 8) จะขึ้นว่า **"ยังไม่มีรอบอัตรากำลังที่เปิดอยู่"**
- **สรุปอัตรากำลัง** — ชีตสรุปของกลุ่มตัวเอง พิมพ์ได้ (ข้อ 10)

จะแจกรหัสตอนนี้เลย หรือรอแจกพร้อมกับตอนเปิดให้กลุ่มสาระกรอกก็ได้

## 7. ทำหลักสูตรก่อน (ผู้ดูแลระบบ · ทุกภาคเรียน)

ทุกแถวของรอบอัตรากำลังมาจากหลักสูตร: **บรรทัดวิชาของหลักสูตร × ห้องเรียนที่ใช้หลักสูตรนั้น** (และตัวเลือกของชุดคาบเสรี/กิจกรรม)
วิชา รหัส หน่วยกิต คาบ/สัปดาห์ ประเภท กลุ่มสาระ และห้อง กำหนดที่หลักสูตรที่เดียว หัวหน้ากลุ่มสาระแก้ส่วนนี้ไม่ได้ จึงต้องทำหลักสูตรให้ถูกก่อนเปิดรอบ

1. เมนู **หลักสูตร** → เลือกภาคเรียน (เช่น 2/2569) ที่ตัวเลือกภาคเรียนด้านบน
2. ภาคเรียนที่ยังไม่มีหลักสูตรจะมีกล่อง **"ตั้งต้นหลักสูตรของภาคเรียน …"** ให้เลือกวิธีเริ่ม (ไม่ต้องพิมพ์จากศูนย์)
   - **ตั้งต้นจากโปรแกรมจัดตาราง** — แปลงแผนการสอนและคาบเสรีที่อยู่ในโปรแกรมจัดตารางตอนนี้เป็นหลักสูตร
     ห้องที่เรียนวิชาเหมือนกันรวมเป็นหลักสูตรเดียว และดึงครู/วิชาที่ยังไม่มีเข้าทะเบียนให้ด้วย ·
     ถ้ามีรายการที่แปลงไม่ได้ เว็บจะแสดงรายการพร้อมเหตุผล ให้เพิ่มเองทีหลัง
   - **คัดลอกหลักสูตร** — เลือก "ภาคเรียนต้นทาง" (เทอมก่อน) แล้วคัดลอกหลักสูตร ห้อง และชุดคาบเสรี/กิจกรรมทั้งหมดมา แล้วแก้เฉพาะส่วนที่ต่าง
   - **เริ่มว่าง** — สร้างหลักสูตรทีละชุดเอง (เหมาะเมื่อหลักสูตรเปลี่ยนมาก)
3. แก้ให้ตรงกับที่โรงเรียนใช้จริง
   - แท็บ **หลักสูตร** → **เปิดดู** หลักสูตรหนึ่ง → **แก้หลักสูตร** (ชื่อ ระดับ ห้องเรียนที่ใช้ · ห้องหนึ่งอยู่ได้หลักสูตรเดียวต่อภาคเรียน)
   - บรรทัดวิชา: **เพิ่มบรรทัด** หรือ **แก้** ที่บรรทัด (รหัส ชื่อ หน่วยกิต คาบ/สัปดาห์ ประเภท **กลุ่มสาระ**) · **ทุกบรรทัดต้องมีกลุ่มสาระ**
     ไม่งั้นไม่มีหัวหน้ากลุ่มคนไหนเห็นแถวนั้น และเปิดให้กลุ่มสาระกรอกไม่ได้ (ข้อ 8)
   - แท็บ **ชุดคาบเสรี/กิจกรรม** → **เพิ่มชุดคาบเสรี/กิจกรรม** หรือ **แก้ชุด** (ชื่อชุด ห้อง คาบ/สัปดาห์) → **เพิ่มตัวเลือก** (วิชาแต่ละตัวในชุด พร้อมกลุ่มสาระที่รับผิดชอบ)
   - ช่องค้นหาด้านบนหาได้ว่าวิชาหนึ่งอยู่ในหลักสูตรหรือชุดไหนบ้าง
4. ทุกการเพิ่ม/แก้/ลบลงแท็บ **บันทึกการแก้** (ใคร เมื่อไหร่ ทำอะไร) ตรวจย้อนได้ทุกเมื่อ
5. **ทุกคนที่ล็อกอินเปิดดูหลักสูตรได้** (หัวหน้ากลุ่มสาระเห็นแบบอ่านอย่างเดียว) — ถ้าหัวหน้าสงสัยว่าวิชาหรือคาบมาจากไหน ให้ดูที่นี่

ระหว่างรอบเปิดอยู่ยังแก้หลักสูตรได้: เพิ่มบรรทัด/ห้อง → แถวใหม่ถูกสร้างให้ในรอบ (ยังไม่มีครู) ·
ลบบรรทัดหรือเอาห้องออกจากหลักสูตร ทั้งที่หัวหน้าใส่ครูไว้แล้ว → เว็บถามยืนยันซ้ำพร้อมจำนวนแถวที่มีครู (ปุ่ม **ลบพร้อมครูที่ใส่ไว้**) ครูที่ใส่ไว้ไม่หายเงียบ ๆ ·
**ปิดรอบแล้ว หลักสูตรของภาคเรียนนั้นแก้ไม่ได้อีกตลอดไป** (เก็บไว้เป็นหลักฐานย้อนหลัง ขึ้นป้าย "ปิดแล้ว · อ่านอย่างเดียว")

## 8. เปิดรอบอัตรากำลัง ตรวจ และปิดรอบ (ผู้ดูแลระบบ)

หนึ่งภาคเรียนมีรอบเดียว และมีรอบที่ยังไม่ปิดได้ทีละรอบ

1. เมนู **รอบอัตรากำลัง** → ใส่ปีการศึกษาและภาคเรียน (เว็บเดาให้) → กด **ดูก่อนเปิด**
   เว็บบอกตัวเลขที่จะได้ เช่น จำนวนแถว ตัวเลือกคาบเสรี/กิจกรรม แถวที่มีครูจากเทอมก่อน และบรรทัดที่ยังไม่มีกลุ่มสาระ · **ยังไม่มีอะไรถูกบันทึก**
   (ถ้าขึ้นว่ายังไม่มีหลักสูตร ให้ทำข้อ 7 ก่อน — มีปุ่ม **ไปหน้าหลักสูตร**)
2. กด **เปิดรอบ** → รอบอยู่ในสถานะ "เตรียม (ยังไม่เปิดให้กรอก)" · **หัวหน้ากลุ่มสาระยังไม่เห็น**
   ตอนเปิดรอบ ถ้าห้องและวิชาตรงกับแผนการสอนของเทอมที่เพิ่งจัดเสร็จ เว็บใส่ครูคนเดิมไว้ให้แบบ "จากเทอมก่อน" (ยังไม่ยืนยัน) · ไม่ตรง = ช่องครูว่าง
3. ถ้ามีบรรทัดหรือตัวเลือกที่ยังไม่มีกลุ่มสาระ หน้าจะเตือนพร้อมปุ่ม **ไประบุกลุ่มสาระที่หน้าหลักสูตร** · ระบุให้ครบก่อน
   (เปิดให้กรอกแล้ว บรรทัดหรือตัวเลือกที่เพิ่มหรือแก้ต้องมีกลุ่มสาระเสมอ — เว็บไม่ยอมให้ตั้งว่าง เพราะแถวที่ไม่มีกลุ่มไม่มีหัวหน้าคนไหนเห็น)
   (ระหว่างนี้ดูหน้าสรุปของรอบได้ — หัวกระดาษมีป้าย "ร่าง — ยังไม่เปิดให้กรอก")
4. กด **เปิดให้กลุ่มสาระกรอก** → หัวหน้ากลุ่มสาระเห็นแถวของกลุ่มตัวเองทันที (นี่คือเวลาแจกรหัส ถ้ายังไม่ได้แจก)
   เปลี่ยนใจก่อนเปิดให้กรอก: **ยกเลิกรอบนี้** (หลักสูตรไม่หาย)
5. หน้ารอบแสดงการ์ดกลุ่มสาระละใบ พร้อมความคืบหน้า · กด **เปิดดู** เพื่อดู/แก้แถวของกลุ่มนั้นแทนหัวหน้าได้ (การแก้ของผู้ดูแลระบบไม่เปลี่ยนสถานะกลุ่ม)
6. เมื่อกลุ่มไหนส่งแล้ว การ์ดขึ้น "ส่งแล้ว รอผู้ดูแลระบบตรวจ"
   - ถูกต้อง → **ตรวจผ่าน**
   - ถ้าการ์ดมีกล่องเหลือง "ตรวจผ่านไม่ได้ — ตั้งแต่กลุ่มส่งมา มีรายการที่ยังไม่มีครู …" (หลักสูตรเพิ่มวิชาให้กลุ่มหลังส่ง หรือมีคนล้างครู)
     ปุ่มตรวจผ่านกดไม่ได้ → **ตีกลับ** ให้กลุ่มกรอกส่วนที่เพิ่มก่อน
   - ต้องแก้ → **ตีกลับ** → เขียนหมายเหตุว่าต้องแก้อะไร (ห้ามว่าง — หัวหน้าเห็นข้อความนี้) → **ยืนยันตีกลับ**
7. เมื่อทุกกลุ่มตรวจผ่านแล้ว กด **ปิดรอบ** → พิมพ์ชื่อรอบ (เช่น 2/2569) ให้ตรง → **ยืนยันปิดรอบ**
   **ปิดแล้วเปิดกลับไม่ได้**: หัวหน้าแก้ไม่ได้อีก หลักสูตรของภาคเรียนนั้นแก้ไม่ได้ตลอดไป รอบย้ายไปอยู่ในรายการรอบเก่า (เปิดดูได้อย่างเดียว)
   — ยกเว้นรอบของภาคเรียนที่กำลังใช้อยู่ในโปรแกรมจัดตาราง ซึ่งผู้ดูแลระบบ **เปิดให้แก้กลางเทอม** ได้ (ข้อ 11ก)
   (ไม่ต้องปิดรอบก่อนส่งเข้าโปรแกรม — รอบที่ทุกกลุ่มตรวจผ่านแล้วส่งได้เลย และการส่งปิดรอบให้เอง)
8. ตอนขึ้นภาคเรียนใหม่: ส่งรอบนี้เข้าโปรแกรมจัดตารางด้วยปุ่ม **สร้างเทอมใหม่** ของโปรแกรมจัดตารางสอน (ข้อ 11)
   ส่งแล้วรอบขึ้นป้าย **"ส่งเข้าโปรแกรมแล้ว — เทอม …"** ในรายการรอบเก่าและในหน้าของรอบ และไม่มีปุ่มแก้อีก

## 9. สำหรับหัวหน้ากลุ่มสาระ

**หน้าที่ของหัวหน้ากลุ่มสาระคือใส่ครูอย่างเดียว** — วิชา รหัส คาบ และห้องเรียน มาจากหลักสูตรที่ผู้ดูแลระบบทำไว้
ถ้าวิชาหรือคาบผิด **ให้แจ้งผู้ดูแลระบบแก้ที่หลักสูตร** (ดูหลักสูตรได้ที่เมนู **หลักสูตร** หรือกดชื่อหลักสูตรใต้ชื่อวิชาบนการ์ด "จากหลักสูตร …")

1. ใส่รหัสของกลุ่ม → เมนู **อัตรากำลังของกลุ่ม** · วิชาจัดเป็นการ์ดละวิชา ในการ์ดมีห้องละแถว · "คาบรายครูของกลุ่ม" อยู่ด้านข้างบนจอกว้าง
   (จอแคบกว่า 1280 พิกเซลรวมโน้ตบุ๊กที่ย่อจอ และโทรศัพท์ อยู่ใต้รายการ ให้ช่องชื่อครูกว้างพออ่านชื่อเต็ม)
2. **ป้าย "จากเทอมก่อน"** = เว็บใส่ครูคนเดิมของห้องนั้นวิชานั้นจากตารางเทอมที่แล้วไว้ให้ **แต่ยังไม่นับว่ายืนยัน**
   - ถูกแล้ว → กด **ยืนยัน** ที่แถวนั้น
   - ไม่ถูก → เลือกครูใหม่ในช่องครูผู้สอน แล้วกด **บันทึกครู** (หรือกด Enter) — บันทึกแล้วนับว่ายืนยันครูคนนั้น
     เลือกแล้วยังไม่กด = **ยังไม่ได้บันทึก** (ช่องเป็นกรอบสีและมีข้อความบอก) · กด **ยกเลิก** เพื่อกลับเป็นครูเดิม
     (การเลื่อนตัวเลือกด้วยลูกศรหรือพิมพ์ตัวอักษรในช่องจึงไม่บันทึกและไม่ยืนยันใครเอง)
3. **ยืนยันทั้งชุด**: ติ๊ก **เลือกทั้งหมด** ในการ์ดวิชา (หรือติ๊กทีละแถว) → **ยืนยันแถวที่เลือก (N)** · แถวที่ยังไม่มีครูยืนยันไม่ได้ ต้องใส่ครูก่อน
   แถวที่เลือกครูใหม่ไว้แต่ยังไม่กด **บันทึกครู** จะ **ถูกข้าม** (ไม่ยืนยันครูคนเดิมแทน) และหน้าบอกว่าข้ามกี่แถว — กดบันทึกครูหรือยกเลิกที่แถวนั้นก่อน
4. **ใส่ครูคนเดียวให้หลายห้อง**: ติ๊กแถวที่ต้องการ → **ใส่ครูให้แถวที่เลือก** → เลือกครู → **ใส่ครู N แถว**
5. ครูสอนร่วม ห้องปฏิบัติการ และหมายเหตุ (ช่อง "รายละเอียด" ของแถว): กด **แก้** → กรอก → **บันทึก** · คาบคู่: ติ๊กช่องคาบคู่ในช่องเดียวกัน (บันทึกทันที ไม่นับเป็นการยืนยัน)
6. ตัวกรองด้านบน: **ทั้งหมด / ยังไม่ยืนยัน / ยืนยันแล้ว** · ค้นหาวิชา ห้อง หรือชื่อครู · เลือกชั้น
7. **คาบเสรี / กิจกรรม** (ท้ายหน้า เฉพาะกลุ่มที่รับผิดชอบตัวเลือก): ตัวเลือกหนึ่งมีครูได้หลายคน
   เลือกครู → **เพิ่มครู** · ครูที่มาจากเทอมก่อนกด **ยืนยัน** · **แก้** (ห้อง หมายเหตุ) · **เอาออก**
   คาบ/สัปดาห์ของชุดนับให้ครูแต่ละคน **ครั้งเดียวต่อชุด** ไม่คูณจำนวนห้อง
8. **กดส่ง**: เมื่อทุกรายการมีครูและยืนยันครบ กด **ส่งให้ผู้ดูแลระบบตรวจ** → **ยืนยันส่ง**
   ถ้ายังไม่ครบ ปุ่มกดไม่ได้และบอกว่าเหลืออะไร · ส่งแล้วหน้าเป็นอ่านอย่างเดียวจนกว่าผู้ดูแลระบบจะตีกลับ
9. **ถ้าถูกตีกลับ**: กล่องสีแดงบนสุดของหน้าแสดงหมายเหตุของผู้ดูแลระบบ → แก้ตามนั้น → กดส่งใหม่
10. ปุ่ม **ดูทั้งหมด · พิมพ์** (ใต้คาบรายครู) พาไปหน้าสรุปของกลุ่ม (ข้อ 10)

ถ้ามีคนอื่นแก้หรือส่งไปก่อน (เช่น เปิดสองเครื่อง) การบันทึกครั้งถัดไปจะขึ้นข้อความบอกเหตุ แล้วหน้าโหลดสถานะใหม่ ค่าที่เลือกค้างไว้ยังอยู่ให้ลองใหม่
เปิดหน้าทิ้งไว้แล้วสลับกลับมา (หรือกดเมนู **อัตรากำลังของกลุ่ม** ซ้ำ) หน้าจะโหลดสถานะกลุ่มล่าสุดเอง เช่น ผู้ดูแลระบบตีกลับแล้วก็เห็นหมายเหตุทันที

## 10. หน้าสรุปอัตรากำลัง (แทนชีต Excel เดิม) และวิธีพิมพ์

เมนู **สรุปอัตรากำลัง** · สดจากรายการของรอบ ไม่ต้องลอกอีก มีสองแบบ (สลับที่ปุ่มด้านบน)
- **แบบรายวิชา** — วิชาไหน ห้องไหน ครูคนไหนสอน · คอลัมน์ ลำดับที่ · ชั้น · ภาคเรียนที่ · รหัสวิชา · ชื่อวิชา · นก. · คาบ/สัปดาห์ · ประเภทวิชา ·
  ห้องที่เรียน · ครูผู้สอน 1 · ครูผู้สอน 2 · วิชาหนึ่งเป็นหนึ่งก้อน บรรทัดแรกมีข้อมูลวิชา บรรทัดถัดไปมีแค่ห้องกับครู ·
  **ครูผู้สอน 2 คือครูสอนร่วม** (ครูอีกคนที่เข้าสอนห้องนั้นด้วยกัน) — หัวคอลัมน์ใช้คำตามแบบฟอร์มเดิม ความหมายบอกไว้ที่บรรทัดหมายเหตุใต้หัวกระดาษ ·
  ตัวเลือกคาบเสรี/กิจกรรมเป็นก้อนละตัวเลือก ห้องคือช่วงห้องของชุด (เช่น ม.1/7-12) · แถวที่ยังไม่มีครูก็อยู่ (ช่องครูเป็น —)
- **แบบครูผู้สอน** — ครูคนไหนสอนอะไร · คอลัมน์ ลำดับที่ · ครูผู้สอน · รหัสวิชา · ชื่อวิชา · นก. · ประเภทวิชา · ห้องที่สอน · คาบ/สัปดาห์ ·
  จำนวนคาบ (ของวิชานั้น) · รวมคาบสอน (ของครูคนนั้น) · ครูที่สอนกลุ่มอื่นด้วยมีบรรทัดท้ายก้อน "สอนกลุ่มอื่น N คาบ · รวมทั้งหมด M คาบ"

ใครเห็นอะไร: **ผู้ดูแลระบบ** เลือกกลุ่มสาระ หรือ "ทุกกลุ่มสาระ" · **หัวหน้ากลุ่มสาระ** เห็นกลุ่มตัวเองเท่านั้น ·
ถ้ามีหลายรอบ เลือกรอบได้ (เริ่มที่รอบที่ยังไม่ปิด) · บรรทัด "ยังไม่ยืนยัน N รายการ" ใต้หัวกระดาษ (และแถวพื้นเหลืองจาง) แปลว่าชื่อครูยังอาจเปลี่ยน

**วิธีพิมพ์**
1. เลือกแบบและกลุ่มสาระที่ต้องการ แล้วกดปุ่ม **พิมพ์** (แถวเดียวกับตัวเลือกแบบและกลุ่มสาระ)
2. ในหน้าต่างพิมพ์ของเบราว์เซอร์: กระดาษ **A4** · แนว **แนวตั้ง** · ถ้าไม่อยากให้วันที่และลิงก์เว็บติดขอบกระดาษ ให้เอาติ๊ก **ส่วนหัวและส่วนท้าย** ออก
   (ใน "การตั้งค่าเพิ่มเติม") · อยากได้ไฟล์แทนกระดาษ เลือกปลายทาง **บันทึกเป็น PDF**
3. บนกระดาษไม่มีแถบเมนูและปุ่ม · หัวกระดาษ 3 บรรทัดกึ่งกลาง (ชื่อชีต · ภาคเรียนที่ N ปีการศึกษา YYYY · กลุ่มสาระ) อยู่หน้าแรก ·
   **หัวตารางซ้ำทุกหน้า** · บรรทัดไม่ถูกตัดครึ่งข้ามหน้า และก้อนสั้น ๆ ไม่แตกข้ามหน้า
4. ป้ายชั้นสีและช่องรหัสวิชาสีเหลืองพิมพ์ติดไปเอง · ถ้าเครื่องไหนสีไม่ติด ให้ติ๊ก **กราฟิกพื้นหลัง** ในการตั้งค่าเพิ่มเติม (พิมพ์ขาวดำก็ยังอ่านได้ เพราะป้ายมีคำ ม.1–ม.6 เสมอ)

## 11. ขึ้นภาคเรียนใหม่ด้วยรอบอัตรากำลัง (ผู้ดูแลระบบ · ในโปรแกรมจัดตารางสอน · ภาคเรียนละครั้ง)

ตอนกด **สร้างเทอมใหม่** ในโปรแกรมจัดตารางสอน เลือกได้ว่าแผนการสอนของเทอมใหม่มาจาก **รอบอัตรากำลัง** ที่ตรวจผ่านแล้ว
แทนการพิมพ์แผนทั้งเทอมใหม่ เทอมใหม่จะเริ่มด้วยแผนการสอน ชุดคาบเสรี และหลักสูตรตามรอบครบ ครูและวิชาที่ยังไม่มีในโปรแกรมถูกสร้างให้
**ตารางยังเริ่มว่างเหมือนเดิม** แล้วไปจัดคาบตามปกติ · การสร้างทั้งหมดเป็นก้อนเดียว ถ้าล้มกลางทาง ทุกอย่างกลับเป็นเหมือนก่อนกด

> **⚠ ห้ามกดบนเว็บจริงจนกว่าจะขึ้นภาคเรียนถัดไปจริง** กดแล้วเทอมที่ใช้อยู่ถูกปิด และคาบที่ลงไว้ทั้งหมดเริ่มจากว่างในเทอมใหม่
> ครั้งแรก **ลองกับสำเนาฐานข้อมูลจริงก่อน** (ข้อ 15) · ทำนอกเวลาเรียน

### ก่อนกด

1. รอบของภาคเรียนใหม่ต้องพร้อม: เปิดให้กลุ่มสาระกรอกแล้ว · ทุกรายการมีครูและยืนยันแล้ว · ทุกกลุ่มสาระที่มีรายการ **ตรวจผ่านแล้ว** (หรือปิดรอบแล้ว) — ข้อ 8
2. ทุกบรรทัดหลักสูตรและทุกตัวเลือกคาบเสรี/กิจกรรมมีรหัสวิชา (ข้อ 7)
3. **ระหว่างกดสร้างเทอมใหม่ อย่าแก้ข้อมูลในโปรแกรมจัดตาราง (ถ้ามีคนแก้ จะได้ข้อความให้กดใหม่)** — บอกคนที่จัดตารางให้หยุดก่อนสักครู่ การกดใช้เวลาไม่กี่วินาที
4. เตรียม **รหัสผู้ดูแลระบบของเว็บลงอัตรากำลัง** (รหัสเดียวกับที่ใช้เข้าเว็บนี้ ข้อ 2) — ต้องกรอกซ้ำตอนกด

### ดูสรุปแล้วกดสร้าง

1. เปิดโปรแกรมจัดตารางสอน → เมนู **⚙ จัดการ** → **🗓 เทอม** → ปุ่ม **＋ สร้างเทอมใหม่**
2. หน้าต่าง "สร้างเทอมใหม่" มีหัวข้อ **แผนการสอนของเทอมใหม่** ให้เลือกสองทาง
   - **ใช้แผนเดิมของเทอมนี้ (ไม่เปลี่ยน)** — แบบที่ใช้มาตลอด (เลือกไว้ให้ตั้งแต่เปิดหน้าต่าง)
   - **จากรอบอัตรากำลัง** แล้วเลือกรอบในช่องข้าง ๆ (เว็บเลือกรอบของ **ภาคเรียนถัดจากเทอมที่ใช้อยู่** ที่ใช้ได้ไว้ให้ — ไม่มี = ยังไม่เลือก
     ให้เลือกเอง) ป้ายในช่องบอกว่ารอบนั้น **ใช้ได้** · **ยังใช้ไม่ได้** ·
     หรือ **ส่งแล้ว (เทอม …)** (รอบที่ส่งแล้วแสดงไว้ให้เห็น แต่เลือกไม่ได้)

   ถ้ายังไม่มีรอบอัตรากำลังเลย หน้าต่างเป็นแบบเดิมทุกอย่าง (ไม่มีสองทางนี้) · ถ้าเซิร์ฟเวอร์อ่านรายการรอบไม่ได้ จะมีบรรทัดเล็กสีเทาบอกท้ายหน้าต่าง
   และยังสร้างเทอมจากแผนเดิมได้ตามปกติ
3. เลือก **จากรอบอัตรากำลัง** แล้ว ปีการศึกษาและภาคเรียนเป็นของรอบ แก้ไม่ได้
4. อ่านสรุป **เทอมใหม่จะเริ่มต้นด้วย** — ยังไม่มีอะไรถูกบันทึก บรรทัดที่เป็นศูนย์ไม่ขึ้น บรรทัดที่มี **ดูรายการ** กดเปิดดูชื่อได้
   - แผนการสอน (แถว) · คาบรวมตามแผน · ครูในแผน · หลักสูตร
   - **ครูใหม่ที่จะสร้าง** / **วิชาใหม่ที่จะสร้าง** — มีในเว็บลงอัตรากำลังแต่ยังไม่มีในโปรแกรม
   - **ครูที่จะถูกแก้ข้อมูล** / **วิชาที่จะถูกแก้ข้อมูล** — ดูรายการทีละคน/วิชา ในรูป "ชื่อ · ช่อง: ค่าเดิม → ค่าใหม่"
     (เช่น ชื่อที่แก้ในเว็บ กลุ่มสาระ คาบคู่ วิชาเสรี) ตรวจให้ถูก เพราะค่าใหม่จะไปแทนในโปรแกรม ·
     ช่องที่โปรแกรมเป็นเจ้าของ (ห้องประจำ คาบสูงสุดต่อวัน วันที่ไม่สอน ฯลฯ) ไม่ถูกแตะ
   - **วิชาที่ผูกกับวิชาเดิมในโปรแกรมด้วยรหัสวิชา** (ⓘ) — วิชาที่พิมพ์รหัสเองในหลักสูตร แล้วรหัสตรงกับวิชาที่มีในโปรแกรม จึงใช้วิชาเดิม ไม่สร้างใหม่
   - **ชุดคาบเสรี** — สร้างให้ครบทุกชุดทุกตัวเลือก **แต่ยังไม่ลงคาบ**
   - **⚠ ชุดกิจกรรมที่ต้องลงคาบเอง** — โปรแกรมเก็บกิจกรรมไว้ในคาบ และตารางของเทอมใหม่เริ่มว่าง จึงต้องลงคาบกิจกรรมเองหลังสร้าง
   - **ⓘ แถวแผนของวิชาเสรี/กิจกรรมที่สร้างตามรูปของแผนเดิม** และ **ⓘ วิชาที่ถูกเพิ่มเข้าหลักสูตร** — แถวแผนที่เทอมเดิมมีสำหรับวิชาในชุด
     (ให้ยอดคาบของครูเท่าเดิม) และวิชาที่โปรแกรมเพิ่มเข้าหลักสูตรของห้องให้แถวเหล่านั้นแก้ได้ตามปกติ — แจ้งให้รู้ ไม่ต้องทำอะไร
   - **ⓘ ห้อง+วิชาที่ยกเซ็ตห้องย่อย/คาบที่ปักจากแผนเดิมไม่ได้** และ **ⓘ ห้อง+วิชาที่ไม่มีในแผนเดิม** — ช่องที่เว็บไม่มี (เซ็ตห้องย่อย
     วัน/คาบที่ปัก คาบคู่ที่ปัก) ยกมาจากแผนเดิมไม่ได้ จึงเริ่มว่าง · กด **ดูรายการ** แล้วตั้งค่าเหล่านั้นใหม่ในโปรแกรมหลังสร้าง (ถ้าต้องใช้)
     — ตอนขึ้นภาคเรียนใหม่ รายการ "ไม่มีในแผนเดิม" **ยาวเป็นร้อยบรรทัดเป็นเรื่องปกติ** เพราะรหัสวิชาเปลี่ยนตามภาคเรียน (เช่น ท21101 → ท21102)
     ไม่ต้องไล่ทุกบรรทัด ดูเฉพาะห้องที่เคยตั้งเซ็ตห้องย่อยหรือปักคาบไว้
   - **⚠ ครู/วิชาที่ปิดใช้งานในโปรแกรม แต่อยู่ในเทอมใหม่** — โปรแกรมไม่เปิดใช้งานให้เอง ถ้าต้องใช้ ให้เปิดในหน้าครู/วิชาของโปรแกรม
   - **ⓘ ครูที่เว็บติ๊กว่าไม่ปฏิบัติงานแล้ว แต่ยังเปิดอยู่ในโปรแกรม** และ **ⓘ ครูในโปรแกรมที่เว็บไม่รู้จัก** — แจ้งให้รู้ ไม่ทำอะไรกับครูเหล่านี้ (ไม่ลบ ไม่ปิด)
   - **คาบที่ลงตารางไว้ตอนนี้** (จะถูกล้าง — เก็บไว้ในเทอมที่ถูกปิด เปิดดูและพิมพ์ได้ภายหลัง)
5. ถ้ามีกล่องแดง **"ยังสร้างเทอมจากรอบนี้ไม่ได้ เพราะ"** ปุ่มสร้างจะกดไม่ได้ — แก้ตามเหตุ (ตารางข้างล่าง) แล้วปิดหน้าต่างและเปิดใหม่
6. กรอก **รหัสผู้ดูแลระบบของเว็บลงอัตรากำลัง** → กด **ปิดเทอมนี้ แล้วสร้างเทอมใหม่จากรอบ** (ปุ่มล็อกทันทีที่กด กดซ้ำไม่ได้)
   - รหัสผิด → ข้อความ "รหัสผู้ดูแลระบบของเว็บลงอัตรากำลังไม่ถูกต้อง — ยังไม่ได้สร้างเทอมใหม่ ข้อมูลเดิมยังอยู่ครบ" แก้รหัสแล้วกดใหม่ได้
     (ผิดหลายครั้งติดกันต้องรอสักครู่ เหมือนหน้าล็อกอิน — ข้อ 13)
   - "ติดต่อฐานข้อมูลไม่ได้ในขณะนี้ ลองใหม่อีกครั้ง" → ยังไม่ได้ทำอะไร รอสักครู่แล้วกดใหม่ได้เลย
   - "สร้างเทอมใหม่ไม่สำเร็จ ข้อมูลเดิมยังอยู่ครบ …" → ปิดหน้าต่าง ดูรายการเทอมก่อน ถ้ายังไม่มีเทอมใหม่ เปิดหน้าต่างใหม่แล้วกดอีกครั้ง
   - ถ้าขึ้นว่า "ไม่ได้รับคำตอบที่แน่ชัดจากเซิร์ฟเวอร์ … อย่ากดสร้างซ้ำ" → ปิดหน้าต่าง แล้วดูรายการเทอมก่อนว่าเทอมใหม่ถูกสร้างหรือยัง

**เหตุที่ใช้ไม่ได้ และวิธีแก้** (ข้อความในกล่องแดงขึ้นต้นแบบนี้)

| ข้อความขึ้นต้นว่า | วิธีแก้ |
|---|---|
| "รอบ … ยังกำลังเตรียม ยังไม่เปิดให้กลุ่มสาระกรอก" | กด **เปิดให้กลุ่มสาระกรอก** ในหน้ารอบ แล้วให้ทุกกลุ่มกรอก (ข้อ 8) |
| "ยังไม่มีครู … รายการ" / "ยังไม่ยืนยัน … รายการ ในกลุ่มสาระ …" | ให้หัวหน้ากลุ่มนั้นใส่ครูและยืนยัน (ข้อ 9) หรือผู้ดูแลระบบกด **เปิดดู** ที่การ์ดกลุ่มแล้วแก้แทน (ข้อ 8) |
| "กลุ่มสาระ…ยังไม่ตรวจผ่าน" | ตรวจผ่านกลุ่มนั้น หรือปิดรอบ (ข้อ 8) |
| "รายการที่ไม่ได้ระบุกลุ่มสาระ … ไม่มีกลุ่มสาระใดตรวจผ่านให้ได้" | ระบุกลุ่มสาระของบรรทัด/ตัวเลือกนั้นในหน้าหลักสูตร (ข้อ 7) หรือปิดรอบ |
| "หลักสูตร …: บรรทัดที่ไม่มีรหัสวิชา" หรือ "…: ตัวเลือกที่ไม่มีรหัสวิชา" | ใส่รหัสวิชาที่บรรทัด/ตัวเลือกนั้นในหน้าหลักสูตร (ข้อ 7) — หลักสูตรแก้ได้เฉพาะก่อนปิดรอบ |
| "…ที่ผูกกับวิชาซึ่งไม่มีรหัสในทะเบียนวิชา" | ใส่รหัสวิชาในหน้า **ทะเบียนวิชา** ของเว็บลงอัตรากำลัง |
| "รหัสวิชา … มีในโปรแกรมจัดตาราง … วิชา" หรือ "รหัสวิชา … ซ้ำกับวิชา …" | แก้รหัสวิชาให้ไม่ซ้ำ ตามที่ข้อความบอก (ในทะเบียนวิชาของเว็บ หรือในโปรแกรมจัดตาราง) |
| "ครูที่ถูกอ้างในรอบ … คนไม่มีในทะเบียนครูของเว็บลงอัตรากำลังแล้ว" | แก้แถว/ตัวเลือกนั้นให้เลือกครูที่มีในทะเบียน |
| "… รายการจะไม่ได้เข้าเทอมใหม่ จึงยังสร้างเทอมไม่ได้" (รายการ **ถูกข้าม** เช่น "ไม่พบห้องเรียนรหัส … ในโปรแกรมจัดตารางแล้ว") | ห้อง ครู หรือวิชานั้นไม่มีในโปรแกรมจัดตารางแล้ว — **ต้องแก้ข้อมูลในโปรแกรมจัดตารางก่อน** (เช่น เพิ่มห้องเรียนที่ถูกลบกลับ) หรือติดต่อผู้ดูแลระบบเครื่อง · โปรแกรมไม่สร้างเทอมที่ขาดรายการแบบเงียบ ๆ |
| "มีเทอม … ในโปรแกรมจัดตารางอยู่แล้ว — สร้างเทอมเดียวกันซ้ำไม่ได้" | สร้างเทอมปี/ภาคเรียนเดิมซ้ำไม่ได้ — ถ้าสร้างผิด ดูหัวข้อ "กดผิด" ข้างล่าง |
| "มีเทอม … ในโปรแกรมจัดตารางอยู่แล้ว (เป็นเทอมที่กำลังใช้อยู่ …)" | รอบนี้เป็นของภาคเรียนที่กำลังใช้อยู่ (ตอนกดสร้าง ตารางที่ลงไว้จะถูกเก็บเป็นเทอมนี้) — ใช้รอบของภาคเรียนถัดไป · ถ้าปี/ภาคในหน้าตั้งค่าผิด ให้แก้ก่อน |
| "ยังไม่มีเทอมใดถูกบันทึกไว้ และระบบบอกไม่ได้ว่าตารางที่ลงไว้ตอนนี้ … เป็นของเทอมไหน" | ตั้งปีการศึกษาและภาคเรียนในหน้าตั้งค่าให้ถูกต้องก่อน แล้วเปิดหน้าต่างใหม่ |
| "เซิร์ฟเวอร์ยังโหลดข้อมูลของโรงเรียนไม่สำเร็จ …" | รอสักครู่แล้วเปิดหน้าต่างใหม่ ถ้ายังขึ้นอยู่ ทำตามข้อ 12 (เริ่มเซิร์ฟเวอร์ใหม่) |

### หลังสร้าง

1. หน้าต่างบอก "สร้างเทอม … แล้ว เทอม … ถูกปิดแล้ว (… คาบ)" ตามด้วยรายการ **ชุดกิจกรรมที่ต้องลงคาบเอง** (ชื่อชุด · ห้อง · คาบ/สัปดาห์ · ครู)
   ดูป้ายสถานะการบันทึกบนแถบด้านบนให้เป็นเวลาล่าสุดก่อนปิดหน้านี้
2. **ลงคาบกิจกรรมเอง** ตามรายการ แบบที่ทำทุกเทอม (เช่นที่หน้า **🤝 คาบกิจกรรมประจำระดับ** ในเมนู ⚙ จัดการ) ·
   ปิดหน้าต่างไปแล้วก็เปิดดูรายการนี้อีกได้ที่เว็บลงอัตรากำลัง: เมนู **รอบอัตรากำลัง** → รอบเก่า → **เปิดดู** → "ชุดกิจกรรมที่ต้องลงคาบเองในโปรแกรมจัดตาราง"
3. ชุดคาบเสรีมีครบแล้ว — จัดคาบเสรีและคาบอื่นตามปกติ (ตารางเริ่มว่าง)
4. ในเว็บลงอัตรากำลัง รอบขึ้นป้าย **"ส่งเข้าโปรแกรมแล้ว — เทอม …"** · รอบนี้และหลักสูตรของภาคเรียนนี้แก้ไม่ได้อีก (ไม่มีปุ่มแก้ · ส่งซ้ำไม่ได้)
   — ถ้าอัตรากำลังเปลี่ยนระหว่างภาคเรียน ให้ **เปิดให้แก้กลางเทอม** แล้วอัปเดตแผนในโปรแกรม (ข้อ 11ก) · ส่งซ้ำด้วยปุ่มสร้างเทอมใหม่ยังไม่ได้เหมือนเดิม
   ครูและวิชาที่ถูกสร้างใหม่ได้เลขของโปรแกรมกลับมาเก็บในทะเบียนของเว็บแล้ว — กดดึงครู/ดึงวิชา (ข้อ 3–4) จะไม่สร้างซ้ำ

### กดผิด (สร้างเร็วไป หรือเลือกผิดรอบ) → ปลดล็อกเทอม

1. โปรแกรมจัดตารางสอน → **⚙ จัดการ** → **🗓 เทอม** → แถวของเทอมเดิมที่ถูกปิด → **ปลดล็อกเทอม** → พิมพ์ชื่อเทอมให้ตรง → **ปลดล็อกเทอมนี้**
   เทอมเดิมกลับมาแก้ได้ทั้งก้อน (รวมคาบที่ลงไว้) และเทอมที่สร้างจากรอบถูกปิดเก็บไว้
2. **ทะเบียนครู/วิชาของเว็บลงอัตรากำลังปรับให้ชี้ตามเทอมที่เปิดอยู่เองทุกครั้งที่ปลดล็อก** ข้อความผลของการปลดล็อกบอกว่าปรับกี่คน/กี่วิชา
   (ถ้ามีรายการที่ปรับไม่ได้ จะบอกชื่อไว้ในข้อความและในประวัติของเทอม) ไม่ต้องทำอะไรเพิ่มในเว็บ
3. **รอบที่ส่งแล้วแก้ไม่ได้** แม้ปลดล็อกเทอมเดิมกลับ (ยกเว้นเปิดให้แก้กลางเทอม ข้อ 11ก — ระหว่างภาคเรียนของเทอมนั้น) · ตอนเทอมของรอบถูกปิดไว้ (เทอมที่เปิดอยู่เก่ากว่า) ป้ายของรอบจะเป็น
   "ส่งเข้าโปรแกรมแล้ว — เทอม … (ถูกปิดไว้ ปลดล็อกเทอมนั้นเพื่อใช้ต่อ)" — เมื่อพร้อมใช้ (ขึ้นภาคเรียนนั้นจริง) ให้ **ปลดล็อกเทอมนั้น** กลับมา
   · ส่วนรอบของภาคเรียนที่ผ่านไปตามปกติ (ขึ้นเทอมใหม่กว่าแล้ว) ป้ายเป็น "ส่งเข้าโปรแกรมแล้ว — เทอม … (ปิดภาคเรียนแล้ว)" — ไม่ต้องทำอะไร
4. **สร้างเทอมปีการศึกษา/ภาคเรียนเดิมซ้ำไม่ได้** — ทางใช้ต่อคือปลดล็อกเทอมนั้นเท่านั้น ถ้าต้องเปลี่ยนแผนหลังจากนั้น ให้ใช้ **อัปเดตแผนจากรอบอัตรากำลัง** (ข้อ 11ก)
   หรือแก้ในโปรแกรมจัดตารางโดยตรง

## 11ก. แก้อัตรากำลังกลางเทอม (ผู้ดูแลระบบ · ระหว่างภาคเรียน)

ระหว่างภาคเรียน อัตรากำลังเปลี่ยนได้ (ครูย้าย ลาออก แบ่งห้องใหม่ เพิ่ม/ลดคาบ) แทนการแก้แผนในโปรแกรมจัดตารางทีละแถวแล้วจำเองว่าคาบไหนต้องตามแก้
ให้แก้ในเว็บนี้ (ที่เดียวกับที่หัวหน้ากลุ่มสาระกรอก) แล้วกด **อัปเดตแผนจากรอบอัตรากำลัง** ในโปรแกรมจัดตารางสอน
โปรแกรมแสดงสิ่งที่ต่างจากแผนแยกเป็นกอง ให้ **ติ๊กรับทีละข้อ** แผนเปลี่ยนเฉพาะข้อที่ติ๊ก (ไม่ติ๊ก = คงเดิม) ·
**คาบที่ลงไว้แล้วไม่ถูกแตะเลย** — สิ่งที่ต้องไปแก้เองในหน้าจัดคาบขึ้นใน **รายการงานที่ต้องไปแก้เอง** ซึ่งหายเองเมื่อแก้แล้ว ·
การอัปเดตเป็นก้อนเดียว ถ้าล้มกลางทาง ทุกอย่างกลับเป็นเหมือนก่อนกด

> **⚠ ครั้งแรกลองกับสำเนาฐานข้อมูลจริงก่อน** (ข้อ 15) · ทำนอกเวลาเรียน · **ระหว่างกดอัปเดต อย่าแก้ข้อมูลในโปรแกรมจัดตาราง**
> (บอกคนที่จัดตารางให้หยุดก่อนสักครู่ — ถ้ามีคนแก้ จะได้ข้อความให้ดูหน้าเทียบใหม่ และยังไม่มีอะไรถูกเขียน)

### ใช้กับรอบไหนได้

- รอบของ **ภาคเรียนที่เปิดอยู่ในโปรแกรมจัดตาราง** เท่านั้น (เทอมที่ใช้งานอยู่ หรือถ้ายังไม่เคยสร้างเทอม = ปีการศึกษา/ภาคเรียนในหน้าตั้งค่าของโปรแกรม)
- รอบที่ **ปิดแล้ว** (เคยส่งด้วยปุ่มสร้างเทอมใหม่หรือไม่ก็ได้) **ใช้ได้เลย ไม่ต้องเปิดให้แก้** — ข้ามไปขั้นที่ 4
  (เช่นภาคเรียนนี้ที่จัดตารางด้วยมือ แล้วอยากให้แผนในโปรแกรมตรงกับรอบ) · **เปิดให้แก้กลางเทอม (ขั้นที่ 1) เฉพาะเมื่อจะแก้รอบ**
  (เปลี่ยนครู คาบ วิชา) เพราะการเปิดให้แก้ส่งทุกกลุ่มสาระกลับเป็น "กำลังกรอก" และรอบจะใช้ไม่ได้จนจบขั้นที่ 3
- รอบที่ **ยังเปิดให้กรอกอยู่** (ไม่เคยปิด) ใช้ได้ตรง ๆ เมื่อทุกกลุ่มตรวจผ่าน หรือเมื่อปิดรอบแล้ว — ข้ามขั้นที่ 1 ข้างล่างได้
- **มีรอบที่ยังไม่ปิดได้ทีละรอบ** — ถ้ามีรอบอื่นเปิดอยู่ (เช่นรอบของภาคเรียนหน้ากำลังเตรียม) เปิดให้แก้ไม่ได้จนกว่าจะปิดหรือยกเลิกรอบนั้น
  ระหว่างนั้นแก้แผนในโปรแกรมจัดตารางด้วยมือได้ตามปกติ

### ขั้นตอน

1. **เปิดให้แก้** (เว็บนี้): เมนู **รอบอัตรากำลัง** → รอบเก่า → **เปิดดู** รอบของภาคเรียนนี้ → **เปิดให้แก้กลางเทอม** → อ่านกล่องยืนยัน → **ยืนยันเปิดให้แก้กลางเทอม**
   - รอบกลับเป็น "เปิดให้กรอก" **ทุกกลุ่มสาระกลับเป็น "กำลังกรอก" รวมกลุ่มที่ไม่ได้แก้อะไร** — **รายการที่ยืนยันแล้วยังยืนยันอยู่**
     หัวหน้าแก้เฉพาะที่เปลี่ยน · หลักสูตรของภาคเรียนนี้แก้ได้อีก · ระหว่างนี้รอบใช้อัปเดตในโปรแกรมไม่ได้ (จนจบขั้นที่ 3)
   - รอบขึ้นป้าย **"แก้กลางเทอม — ยังไม่ส่ง"** และแถบบนขึ้น "ภาคเรียน … · แก้กลางเทอม" (หัวหน้ากลุ่มสาระเห็นด้วย)
   - ถ้ามีรอบอื่นที่ยังไม่ปิด หน้าจะบอกชื่อรอบนั้นแทนปุ่ม · รอบที่ส่งแล้วซึ่งภาคเรียนผ่านไปแล้ว (ป้าย "ปิดภาคเรียนแล้ว"/"ถูกปิดไว้") ไม่มีปุ่มนี้
   - เปิดผิดรอบ/ไม่แก้แล้ว: **ปิดรอบ** ตามปกติ (ข้อ 8) — รอบกลับเป็นปิด ป้ายแก้กลางเทอมหายไป
2. **แก้** (เว็บนี้): ผู้ดูแลระบบแก้หลักสูตร (วิชา คาบ) ถ้าจำเป็น (ข้อ 7) · หัวหน้ากลุ่มสาระเปลี่ยนครูในแถวที่เปลี่ยน (ข้อ 9)
   หรือผู้ดูแลระบบกด **เปิดดู** ที่การ์ดกลุ่มแล้วแก้แทน (ข้อ 8)
3. **ทำให้รอบใช้ได้อีก** (เว็บนี้) — เลือกทางใดทางหนึ่ง
   - **(ก) ปิดรอบ** เมื่อแก้เสร็จ: **ปิดรอบ** → พิมพ์ชื่อรอบ → **ยืนยันปิดรอบ** (ข้อ 8 ข้อ 7) — รอบที่ปิดแล้วใช้อัปเดตได้ทันที
     ป้าย "แก้กลางเทอม" หายไป ไม่ต้องรอทุกกลุ่มส่ง (ปิดแล้วหัวหน้าแก้ต่อไม่ได้ — ถ้าต้องแก้อีก ให้เปิดให้แก้ใหม่) · เหมาะเมื่อแก้แค่ไม่กี่แถว
   - **(ข) ทุกกลุ่มที่มีรายการส่งใหม่ แล้วผู้ดูแลระบบตรวจผ่านทุกกลุ่ม** (ข้อ 8–9) — **รวมกลุ่มที่ไม่ได้แก้อะไร** (หัวหน้ากด **ส่ง** ได้เลย
     เพราะรายการยังยืนยันอยู่) · ผู้ดูแลระบบส่งแทนหัวหน้าไม่ได้ — ถ้ามีกลุ่มที่หัวหน้าไม่เข้าระบบ ให้ใช้ทาง (ก)
   - ทั้งสองทาง ทุกรายการต้องมีครูและยืนยันแล้ว (แถวของบรรทัดหลักสูตรที่เพิ่มใหม่ต้องใส่ครู) — ถ้ายังขาดจะขึ้นในกล่องแดงของขั้นที่ 4
4. **อัปเดตในโปรแกรม** (โปรแกรมจัดตารางสอน): เมนู **⚙ จัดการ** → **🗓 เทอม** → ปุ่ม **อัปเดตแผนจากรอบอัตรากำลัง**
   (ปุ่มขึ้นเมื่อมีรอบของภาคเรียนที่เปิดอยู่ · ไม่ขึ้นระหว่างเปิดดูเทอมที่ปิดแล้ว — กด "กลับไปเทอมปัจจุบัน" ก่อน)
   - มีหลายรอบให้เลือกในช่อง **รอบอัตรากำลัง** · ถ้ามีกล่องแดง **"ยังอัปเดตแผนจากรอบนี้ไม่ได้ เพราะ"** แก้ตามเหตุ (ตารางในข้อ 11 ใช้ได้เหมือนกัน ·
     "รอบนี้เป็นของภาคเรียน … แต่ภาคเรียนที่เปิดอยู่ในโปรแกรมจัดตารางคือ …" = ใช้ได้เฉพาะรอบของภาคเรียนที่เปิดอยู่ ·
     "กลุ่มสาระ…ยังไม่ตรวจผ่าน" หลังเปิดให้แก้ = ยังไม่จบขั้นที่ 3) แล้วกด **ดูใหม่** ในกล่องแดง (หรือปิดหน้าต่างแล้วเปิดใหม่)
   - **"แผนการสอนตรงกับรอบนี้แล้ว — ไม่มีอะไรต้องอัปเดต"** = รอบกับแผนตรงกันทุกข้อ (เช่นรอบที่เปิดจากแผนปัจจุบันของโปรแกรม
     แล้วยังไม่มีใครแก้ทั้งรอบและแผน) · ถ้าแผนในโปรแกรมถูกแก้ด้วยมือหลังเปิดรอบ หน้าเทียบจะมีข้อของส่วนที่ต่างกันจริง — อ่านก่อนติ๊ก
5. **ติ๊กทีละข้อ**: ทุกข้อเริ่มแบบ **ไม่ติ๊ก** · แต่ละกองมี **เลือกทั้งกอง** · ใต้แต่ละข้อบอก **ผลต่อคาบที่ลงไว้แล้ว**
   (เช่น "ลงไว้แล้ว 2 คาบ ขาด 1 คาบ — จะเข้ารายการงาน") ซึ่งเป็นสิ่งที่จะเกิดจริงเมื่อกด

   | กอง | หมายถึง | ติ๊กแล้วเกิดอะไร |
   |---|---|---|
   | **ข้อมูลครู/วิชา** | ครู/วิชาที่ยังไม่มีในโปรแกรม หรือชื่อ/รหัส/กลุ่มสาระที่ต่างจากทะเบียนของเว็บ | สร้างหรือแก้ให้ตรง (ไม่ลบ ไม่แตะช่องของโปรแกรม เช่นห้องประจำ วันที่ไม่สอน) |
   | **แถวใหม่** | ห้อง+วิชาที่รอบมีแต่แผนยังไม่มี | เพิ่มแถวแผน |
   | **คาบเปลี่ยน** | คาบ/สัปดาห์ต่างจากแผน | แก้จำนวนคาบในแผน → รายการงาน "ขาด/เกินแผน … คาบ" ถ้าลงคาบไว้แล้ว |
   | **เปลี่ยนครู** | ครูผู้สอน ครูสอนร่วม หรือห้องปฏิบัติการต่าง | แก้ช่องนั้นในแผน → รายการงาน "คาบที่ลงไว้ยังเป็นครูเดิม" ถ้าลงคาบไว้แล้ว |
   | **แถวที่หายไป** | ห้อง+วิชาที่แผนมีแต่รอบไม่มีแล้ว | ลบแถวแผน → รายการงาน "เกินแผน … คาบ" (**คาบยังอยู่** ลบเองถ้าไม่สอนแล้ว) |
   | **คาบเสรี/กิจกรรม** | ชุดคาบเสรี/กิจกรรมที่ต่าง | ชุดที่ **ยังไม่ลงคาบ** แก้รายการตัวเลือกให้ · ชุดใหม่สร้างแบบยังไม่ลงคาบ · **ชุดที่ลงคาบแล้วและกิจกรรมไม่แก้ให้** (⚠) เข้ารายการงานเท่านั้น |

   - ติ๊กข้อที่ใช้ครู/วิชาที่ยังไม่มีในโปรแกรม → ข้อสร้างครู/วิชานั้นถูกติ๊กให้ด้วย (ข้อนั้นบอกว่า "ติ๊กไว้เพราะข้อที่เลือก … ต้องใช้") ·
     เอาข้อสร้างครู/วิชาออก → ข้อที่ใช้มันถูกเอาออกด้วย
   - เปิดดูได้ ไม่ทำอะไร: **ไม่อยู่ในรอบ — ไม่ทำอะไร** (แถวในแผนที่รอบไม่รู้จัก — ไม่ถูกเสนอให้ลบ) · **จับคู่ไม่ได้ — ไม่ทำอะไร** (ชุดคาบเสรี/กิจกรรม
     ที่จับคู่ไม่ได้ — แก้เองในหน้าจัดคาบถ้าต้องเปลี่ยน) · **อยู่ในรายการงานแล้ว** (ข้อที่ทำได้แค่เข้ารายการงาน และมีในรายการงานที่ยังไม่ทำอยู่แล้ว)
6. กรอก **รหัสผู้ดูแลระบบของเว็บลงอัตรากำลัง** (รหัสเดียวกับที่ใช้เข้าเว็บนี้ — พิมพ์เองทุกครั้ง) → กด **ยืนยัน N ข้อ** (N = จำนวนข้อที่ติ๊ก)
   - สำเร็จ: กล่องเขียว "อัปเดตแผนแล้ว: ยอมรับ … ข้อ · ไม่ยอมรับ … ข้อ · รายการงานใหม่ … ข้อ — คาบที่ลงไว้ไม่ถูกแตะ" (+ "รอบกลับเป็นปิดแล้ว" สำหรับรอบที่เปิดให้แก้)
     หน้าต่างโหลดหน้าเทียบใหม่ทันที (ข้อที่รับแล้วหายไป) ก่อนให้กดอีก · กด **ดูรายการงาน** เพื่อไปที่รายการงาน
   - รอบที่เปิดให้แก้กลางเทอม **กลับเป็นปิดเอง** หลังอัปเดตสำเร็จ · ในเว็บนี้หน้ารอบมี **ประวัติการอัปเดตแผนกลางเทอม** (เมื่อไหร่ · ใคร · ยอมรับ/ไม่ยอมรับกี่ข้อ · กด **ดูข้อ**)
   - ต้องแก้อีกครั้งภายหลัง: เปิดให้แก้กลางเทอมใหม่ (ขั้นที่ 1) ได้ตลอดภาคเรียน
7. **รายการงานที่ต้องไปแก้เอง** (ท้ายหน้า 🗓 เทอม · ข้างปุ่มมี **รายการงาน · ค้าง N**):
   - "ขาด … คาบ" → ลงคาบเพิ่มในหน้าจัดคาบ · "เกินแผน … คาบ" → ลบคาบที่ไม่สอนแล้ว · "คาบที่ลงไว้ยังเป็นครูเดิม" → เปลี่ยนครูของคาบในหน้าจัดคาบ
     — ข้อเหล่านี้ **เป็น "เรียบร้อย" เอง** เมื่อแผนกับคาบตรงกัน (กด **↻ ตรวจสถานะใหม่** เพื่อดูสถานะล่าสุด) และซ่อนไม่ได้ระหว่างที่ยังค้าง
   - **คาบเสรีที่ลงคาบแล้วและกิจกรรม โปรแกรมไม่แก้ให้** (การแก้ตัวเลือกของคาบเสรีที่ลงแล้วต้องเขียนคาบใหม่) → แก้เองในหน้าจัดคาบ แล้วกด **ทำแล้ว**
   - ข้อที่เรียบร้อยแล้ว กด **ทำแล้ว** เพื่อซ่อน · ดูข้อที่ซ่อนได้ที่ **ข้อที่ซ่อนไว้** → **เอากลับมา**
   - รายการงานเป็นของภาคเรียนนั้น: สร้างเทอมใหม่แล้วเริ่มว่าง · ปลดล็อกเทอมเก่ากลับมาได้รายการของเทอมนั้น

### ถ้าเจอข้อความ

| ข้อความขึ้นต้นว่า | วิธีแก้ |
|---|---|
| "ข้อมูลเปลี่ยนตั้งแต่เปิดหน้าเทียบ — ดูใหม่อีกครั้ง" | มีคนแก้รอบหรือแผน หรือมีการอัปเดตครั้งอื่นหลังเปิดหน้าต่าง — กด **ดูใหม่** แล้วติ๊กใหม่จากหน้าเทียบล่าสุด (ยังไม่มีอะไรถูกเขียน) |
| "มีการแก้ข้อมูลในโปรแกรมจัดตารางระหว่างอัปเดตแผน …" | บอกคนที่จัดตารางให้หยุดก่อนสักครู่ แล้วกด **ดูใหม่** และกดอีกครั้ง |
| "รหัสผู้ดูแลระบบของเว็บลงอัตรากำลังไม่ถูกต้อง — ยังไม่ได้อัปเดตแผน …" | แก้รหัสแล้วกดใหม่ได้เลย (ผิดหลายครั้งติดกันต้องรอสักครู่ — ข้อ 13) |
| "อัปเดตแผนไม่สำเร็จ — ยังไม่ได้อัปเดต ข้อมูลเดิมยังอยู่ครบ …" หรือ "ไม่ได้รับคำตอบที่แน่ชัดจากเซิร์ฟเวอร์ …" | กด **ดูใหม่** — ข้อที่ติ๊กหายจากหน้าเทียบแล้ว = อัปเดตไปแล้ว · ยังอยู่ = ติ๊กแล้วกดอีกครั้ง (กดซ้ำด้วยหน้าเดิมไม่มีทางเขียนซ้ำ) |
| (เว็บนี้) "มีรอบ … ที่ยังไม่ปิดอยู่ — รอบที่ยังไม่ปิดมีได้ทีละรอบ …" | ปิดหรือยกเลิกรอบนั้นก่อน (ข้อ 8) หรือแก้แผนในโปรแกรมจัดตารางด้วยมือ |
| (เว็บนี้) "รอบ … ไม่ใช่รอบของภาคเรียนที่เปิดอยู่ในโปรแกรมจัดตาราง …" | เปิดให้แก้ได้เฉพาะรอบของภาคเรียนที่กำลังใช้อยู่ · ถ้าปี/ภาคในหน้าตั้งค่าของโปรแกรมผิด (ยังไม่เคยสร้างเทอม) ให้แก้ก่อน |
| (เว็บนี้) "เทอม … ปิดแล้ว (กำลังเปิดดูเทอมเก่า) …" | ปลดล็อกเทอมปัจจุบันกลับในหน้ารายการเทอมของโปรแกรมจัดตารางก่อน |

## 12. ถ้าเจอข้อความผิดปกติ

ทุกข้อที่ให้กด Save Changes หรือ Manual Deploy บน Render จะทำให้โปรแกรมจัดตารางใช้ไม่ได้ 1-3 นาที (ดูคำเตือนในข้อ 1) ให้ทำตอนที่ไม่มีใครกำลังจัดตาราง

- **"เซิร์ฟเวอร์ยังเป็นรุ่นที่ยังไม่มีเว็บลงอัตรากำลัง กรุณาแจ้งผู้ดูแลระบบ"** → เซิร์ฟเวอร์บน Render ยังไม่ได้รับรุ่นใหม่
  ไปที่ Render → บริการ `school-scheduler` → **Manual Deploy** → **Deploy latest commit** แล้วรอจนสถานะเป็น Live
- **"ติดต่อเซิร์ฟเวอร์ไม่ได้ เซิร์ฟเวอร์อาจกำลังตื่น รอสักครู่แล้วลองใหม่"** → เซิร์ฟเวอร์หลับเมื่อไม่มีคนใช้ รอได้นานถึงหนึ่งนาทีแล้วโหลดหน้าใหม่
- **"ต่อฐานข้อมูลไม่ได้ จึงใช้เว็บลงอัตรากำลังไม่ได้ในตอนนี้ ลองใหม่อีกครั้งภายหลัง"** หรือ **"ต่อฐานข้อมูลไม่ได้ในตอนนี้ ลองใหม่อีกครั้งภายหลัง"**
  → รอสองสามนาทีแล้วโหลดหน้าใหม่ก่อน ถ้ารอแล้วยังขึ้นอยู่ แปลว่าเซิร์ฟเวอร์เริ่มทำงานตอนที่ฐานข้อมูลยังไม่พร้อม ต้องเริ่มเซิร์ฟเวอร์ใหม่:
  Render → บริการ `school-scheduler` → **Manual Deploy** → **Deploy latest commit** แล้วรอจนสถานะเป็น Live
- **"เกิดข้อผิดพลาดที่เซิร์ฟเวอร์ ทำรายการไม่สำเร็จ ลองใหม่อีกครั้ง ถ้ายังไม่ได้ให้แจ้งผู้ดูแลระบบ"** → สิ่งที่เพิ่งทำยังไม่ถูกบันทึก
  ลองทำใหม่หนึ่งครั้ง ถ้ายังขึ้นข้อความเดิม ให้แจ้งผู้ดูแลระบบเครื่อง (บอกว่ากดอะไร ตอนกี่โมง) ไม่ต้องกดซ้ำไปเรื่อย ๆ
- **"รหัสตั้งค่า WORKLOAD_SETUP_CODE บน Render สั้นเกินไป ต้องยาวอย่างน้อย 12 ตัวอักษร"** → แก้ค่าบน Render ให้ยาวพอ แล้วกด Save Changes (รอเซิร์ฟเวอร์เริ่มใหม่)

## 13. เรื่องที่ต้องรู้

- **รหัสนี้ป้องกันได้แค่เว็บลงอัตรากำลังเท่านั้น** โปรแกรมจัดตารางสอนยังไม่มีระบบล็อกอิน ใครที่รู้ลิงก์ยังเข้าไปแก้ตารางได้
- หนึ่งครั้งที่ใส่รหัส อยู่ในระบบได้ **12 ชั่วโมง** แล้วต้องใส่ใหม่
- ปิดแท็บหรือปิดเบราว์เซอร์แล้ว ส่วนใหญ่ต้องใส่รหัสใหม่ **แต่ไม่เสมอไป**: เบราว์เซอร์ที่ตั้งให้เปิดแท็บเดิมต่อเมื่อเปิดใหม่ อาจกู้การเข้าระบบกลับมาได้ (ภายใน 12 ชั่วโมง)
  ดังนั้นบนเครื่องที่ใช้ร่วมกัน **ให้กด "ออกจากระบบ" ทุกครั้งที่เลิกใช้**
- รหัสกลุ่มสาระเดียวกันใช้พร้อมกันหลายเครื่องได้
- เปลี่ยนหัวหน้ากลุ่มสาระ ให้ **ตั้งรหัสใหม่** หรือ **ปิด** รหัสของกลุ่มนั้นทันที
- พิมพ์รหัสผิดหลายครั้งติดกัน (รวมทุกคนประมาณ 10 ครั้งใน 1 นาที) ระบบจะให้รอประมาณหนึ่งนาทีก่อนลองใหม่
- **ลืมรหัสผู้ดูแลระบบ:** ทำข้อ 1 และ 2 ซ้ำ (ใส่ `WORKLOAD_SETUP_CODE` บน Render ใหม่ แล้วกดลิงก์ **"ลืมรหัสผู้ดูแลระบบ"** ที่หน้าล็อกอิน) เสร็จแล้วลบตัวแปรทิ้งอีกครั้ง
  การใส่และลบตัวแปรต้องกด Save Changes สองครั้ง แต่ละครั้งโปรแกรมจัดตารางจะใช้ไม่ได้ 1-3 นาที (ดูคำเตือนในข้อ 1) ให้ทำตอนที่ไม่มีใครกำลังจัดตาราง
- **ไม่มีปุ่มลบครูหรือวิชา** ถ้าครูย้ายหรือเกษียณ ให้ติ๊ก **"ไม่ปฏิบัติงานแล้ว"** (วิชาใช้ "ไม่เปิดสอนแล้ว")
  ครูที่ "ไม่ปฏิบัติงานแล้ว" แต่ยังอยู่ในแถวของรอบ ยังขึ้นชื่อในแถวนั้นตามเดิม แค่ไม่มีให้เลือกใหม่

## 14. เรื่องที่ต้องรู้เพิ่ม (รอบอัตรากำลัง)

- **รอบอัตรากำลังไม่แตะตารางสอนเลย** — เปิดรอบ ใส่ครู ส่ง ตรวจ ปิดรอบ ไม่มีขั้นไหนเขียนข้อมูลของโปรแกรมจัดตารางสอน (ตัวเลข `revision` ไม่ขยับ)
  และไม่ทำให้เซิร์ฟเวอร์เริ่มใหม่ ทำระหว่างที่คนอื่นจัดตารางอยู่ได้
- **อัตรากำลังเข้าไปในโปรแกรมจัดตารางได้สองทางเท่านั้น**: ปุ่มสร้างเทอมใหม่จากรอบ (ข้อ 11 ภาคเรียนละครั้ง) และปุ่มอัปเดตแผนจากรอบอัตรากำลัง
  (ข้อ 11ก ระหว่างภาคเรียน — เฉพาะข้อที่ติ๊ก และไม่แตะคาบที่ลงไว้) · แก้แผนในโปรแกรมจัดตารางโดยตรงด้วยมือก็ยังทำได้ตามปกติ
- "ตั้งต้นจากโปรแกรมจัดตาราง" (ข้อ 7) และครู "จากเทอมก่อน" ตอนเปิดรอบ (ข้อ 8) อ่านแผนการสอนที่อยู่ในโปรแกรมจัดตาราง **ณ ตอนที่กด** (อ่านอย่างเดียว ไม่แก้อะไร)
- **ยอดคาบในหน้าสรุปต่างจากยอดตามแผนในโปรแกรมจัดตารางได้ สำหรับครูที่สอนคาบเสรี/กิจกรรม** — เว็บนี้นับคาบเสรีให้ครูของแต่ละตัวเลือก
  เท่ากับคาบ/สัปดาห์ของชุด **ครั้งเดียวต่อชุด** (นักเรียนหลายห้องเรียนรวมในคาบเดียวกัน จึงไม่คูณจำนวนห้อง) ส่วนยอดตามแผนของโปรแกรมจัดตารางไม่นับชุดคาบเสรีเลย
  ยอดของครูที่สอนคาบเสรีในเว็บนี้จึงมากกว่าโดยตั้งใจ · ตอนเปิดรอบ (ก่อนมีใครแก้) ครูที่ไม่มีคาบเสรี กิจกรรมทั้งระดับ หรือสอนร่วม
  ได้ยอดเท่ากับโปรแกรมจัดตารางทุกคน (มีตัวทดสอบเทียบ)
- ครูสอนร่วมได้คาบ/สัปดาห์ของแถวนั้นเท่ากับครูผู้สอน (ทั้งสองคนเข้าห้องจริง)
- หัวหน้ากลุ่มสาระเห็นยอดรวมทั้งรอบของครูทุกคนที่อยู่ในรายการของกลุ่ม (รวมคาบที่สอนกลุ่มอื่น) แต่ไม่เห็นแถวของกลุ่มอื่น
- ป้าย "ยังไม่ยืนยัน" หายได้เพราะคนกดเท่านั้น (กด **ยืนยัน** หรือเลือกครูเองแล้วกด **บันทึกครู**) — แก้หมายเหตุหรือคาบคู่ไม่ได้ยืนยันแทน
  และการเลื่อนตัวเลือกในช่องครูด้วยลูกศร/ตัวอักษรไม่บันทึกอะไร

## 15. ต้องลองด้วยมือก่อนให้คนในโรงเรียนใช้

ลองจากที่นี่ (เครื่องพัฒนา) ไม่ได้ เพราะเข้าฐานข้อมูลจริงของโรงเรียนไม่ได้ ติ๊กเมื่อทำแล้ว

- [ ] กดดึงครูจาก **สำเนา** ฐานข้อมูลจริง แล้วนับว่าได้ครูเท่ากับที่เว็บตารางมี
- [ ] ขณะกรอกในเว็บใหม่ เปิดเว็บตารางอีกเครื่องค้างไว้ — ตัวเลข `revision` ที่ `/api/state/version` ต้องไม่ขยับเลย และหน้าตารางต้องไม่รีโหลด
- [ ] ปิดเทอมในเว็บตาราง แล้วยืนยันว่าเว็บใหม่ยังกรอกได้
- [ ] ล็อกอินด้วยรหัสกลุ่มสาระเดียวกันสองเครื่องพร้อมกัน ทั้งคู่ต้องใช้งานได้
- [ ] ตั้งต้นหลักสูตรจาก **สำเนา** ฐานข้อมูลจริง แล้วเปิดรอบ — จำนวนแถวต้องสมเหตุสมผลกับจำนวนห้องและวิชาของโรงเรียน และไม่มีรายการที่แปลงไม่ได้ที่ไม่รู้ที่มา
- [ ] **สเปกหลักข้อ 7:** เปิดหน้าสรุปแบบครูผู้สอนของ **อย่างน้อยสองกลุ่มสาระ** เทียบช่อง "รวมคาบสอน" ของครูทุกคนกับชีต (ครูผู้สอน) ของไฟล์ Excel เดิม
  (ไฟล์ Excel ไม่อยู่ในโปรเจกต์ จึงต้องเทียบเอง · ครูที่สอนคาบเสรีต่างได้ตามข้อ 14 — ให้ดูว่าส่วนต่างเท่ากับคาบเสรีที่ชีตเดิมไม่ได้นับหรือนับต่างกัน)
- [ ] กด **พิมพ์** จากเครื่องในห้องพักครูหนึ่งครั้ง ตรวจว่ากระดาษเป็น A4 แนวตั้ง หัวตารางซ้ำทุกหน้า และป้ายสีติด
- [ ] **ลองกับสำเนาฐานข้อมูลจริงก่อนกดบนเว็บจริงครั้งแรก** (ข้อ 11 · ให้ผู้ดูแลระบบเครื่องเตรียมเซิร์ฟเวอร์ทดลองที่ต่อ **สำเนา** ฐานข้อมูล ห้ามลองบนเว็บจริง)
  ข้อนี้รวมการลองปุ่มสร้างเทอมใหม่แบบเดิมที่ยังไม่เคยกดกับข้อมูลจริงด้วย
  - สร้างเทอมใหม่จากรอบที่ตรวจผ่านแล้ว → เทอมใหม่มีแผนการสอนเท่ากับจำนวนแถวที่สรุปบอก · ครูใหม่และวิชาใหม่ขึ้นในโปรแกรม · ชุดคาบเสรีครบทุกตัวเลือก
  - ยอดคาบรายครูในโปรแกรมจัดตารางเทียบกับหน้าสรุปอัตรากำลังของรอบ (ต่างได้เฉพาะครูที่สอนคาบเสรี/กิจกรรม ตามข้อ 14)
  - หน้าจัดคาบเปิดได้ ลงคาบได้ และสั่งจัดคาบอัตโนมัติได้
  - ในเว็บลงอัตรากำลัง รอบขึ้นป้าย "ส่งเข้าโปรแกรมแล้ว — เทอม …" และกดดึงครู/ดึงวิชาจากโปรแกรม (ข้อ 3–4) แล้วไม่มีครูหรือวิชาถูกสร้างซ้ำ
  - ลอง "กดผิด": ปลดล็อกเทอมเดิมกลับ แล้วปลดล็อกเทอมใหม่กลับอีกครั้ง — ทุกครั้งกดดึงครู/ดึงวิชาแล้วไม่มีอะไรถูกสร้างซ้ำ
- [ ] **แก้อัตรากำลังกลางเทอม (ข้อ 11ก) กับสำเนาฐานข้อมูลจริงก่อนใช้กับเทอมจริงครั้งแรก** (เซิร์ฟเวอร์ทดลองที่ต่อ **สำเนา** ฐานข้อมูล ห้ามลองบนเว็บจริง)
  - กด **อัปเดตแผนจากรอบอัตรากำลัง** กับรอบที่ปิดแล้วของภาคเรียนปัจจุบัน **โดยไม่ต้องเปิดให้แก้และยังไม่แก้อะไร** → อ่านหน้าเทียบ:
    ถ้ารอบนั้นเปิดจากแผนปัจจุบันของโปรแกรม (หลังเปิดรอบไม่มีใครแก้แผนหรือรอบ) ต้องขึ้น "แผนการสอนตรงกับรอบนี้แล้ว" (ทุกกองว่าง) ·
    ถ้าแผนในโปรแกรมถูกแก้ด้วยมือหลังเปิดรอบ (เช่นภาคนี้ที่จัดตารางด้วยมือ) ข้อที่ขึ้นต้องเป็นส่วนที่รู้อยู่แล้วว่าต่างกันจริงเท่านั้น —
    ถ้ามีข้อที่อธิบายไม่ได้ ให้จดข้อนั้นไว้แล้วแจ้งผู้ดูแลระบบเครื่อง **ก่อน** ใช้กับเทอมจริง (ยังไม่ต้องกดยืนยัน)
  - เปิดให้แก้กลางเทอม → แก้ในเว็บให้มีครบทุกกอง (ครูใหม่ · แถวใหม่ · คาบเปลี่ยน · เปลี่ยนครูของห้องที่ลงคาบแล้ว · ลบบรรทัด ·
    เปลี่ยนครูของคาบเสรีที่ลง/ยังไม่ลงคาบ) → **ปิดรอบ** (ทาง (ก) ของขั้นที่ 3) — ปุ่มในโปรแกรมใช้ได้ทันทีโดยไม่ต้องให้ทุกกลุ่มส่ง
    → หน้าเทียบขึ้นครบทุกกอง และทุกข้อเริ่มแบบไม่ติ๊ก
  - ติ๊กบางข้อ → กด → แผนเปลี่ยนเฉพาะข้อนั้น · **ตารางสอนในหน้าจัดคาบเหมือนเดิมทุกคาบ** (เทียบภาพก่อน/หลัง หรือจำนวนคาบในหน้าสถิติ)
  - รายการงานขึ้นตามข้อที่ติ๊ก · ลงคาบเพิ่ม/เปลี่ยนครูของคาบตามรายการ แล้วกด **↻ ตรวจสถานะใหม่** → ข้อเป็น "เรียบร้อย" เอง
  - เปิดหน้าต่างค้างไว้ แล้วให้อีกเครื่องแก้แผนในโปรแกรม → กดยืนยัน → ได้ "ข้อมูลเปลี่ยนตั้งแต่เปิดหน้าเทียบ — ดูใหม่อีกครั้ง" และแผนไม่เปลี่ยน
  - กรอกรหัสผิด → ได้ข้อความรหัสผิด และแผนไม่เปลี่ยน
  - หลังอัปเดต: รอบเป็นปิด ไม่มีป้ายแก้กลางเทอม · หน้ารอบในเว็บมีประวัติการอัปเดต · กดดึงครู/ดึงวิชา (ข้อ 3–4) แล้วไม่มีครูหรือวิชาถูกสร้างซ้ำ

## 16. ข้อสอบของสเปก (ส่วนที่ 11): ข้อไหนผ่านแล้ว ข้อไหนยังค้าง

### ทะเบียนครูและวิชา (ข้อ 10ก–10ฉ)

ผลด้านล่างได้จากเซิร์ฟเวอร์จริงในเครื่องพัฒนา (ฐานข้อมูลทดลอง ครู 143 คน) เมื่อ 9 พ.ย. 2569 (ค.ศ. 2026-11-09)
**ไม่ได้แทนการลองกับสำเนาฐานข้อมูลจริงของโรงเรียน** (ข้อ 15 ข้างบนยังต้องทำ)
ข้อที่ขึ้นว่า "รอแผนขั้นที่ 3" — ขั้นที่ 3 (ข้อ 11) มีในรุ่นนี้แล้วและลองกับฐานข้อมูลทดลองในเครื่องพัฒนาแล้ว แต่ตารางนี้ยังเป็นผลของวันที่ข้างบน
ให้ถือว่ายังค้างจนกว่าจะลองกับสำเนาฐานข้อมูลจริงตามข้อ 15

| ข้อ | เรื่อง | สถานะ |
|---|---|---|
| 10ก | แก้ชื่อครูแล้วช่องเงื่อนไขต้องไม่เปลี่ยน | ยังค้าง รอแผนขั้นที่ 3 (ปุ่มส่งเข้าโปรแกรม) |
| 10ข | ครูใหม่จากการอัปเดตมีค่าตั้งต้นของเครื่องครบ | ยังค้าง รอแผนขั้นที่ 3 |
| 10ค | กดอัปเดตสองครั้งต้องไม่สร้างซ้ำ | **ผ่านครึ่งเดียว:** ฝั่งดึงครู กดสองครั้งติดกันไม่มีครูถูกสร้างเพิ่ม (จอขึ้น "ไม่มีครูใหม่ให้ดึง (มีอยู่แล้ว 143 คน)") ครูคงที่ 143 คน · ฝั่งไม่สร้างวิชาซ้ำ ยังค้าง รอแผนขั้นที่ 3 |
| 10ง | ครูที่ไม่มีในเว็บใหม่ต้องขึ้นให้อ่านและไม่ถูกลบ | ยังค้าง รอแผนขั้นที่ 3 |
| 10จ | ดึงครูเทียบด้วยเลขครูของโปรแกรมจัดตาราง ไม่ใช่ชื่อ | **ผ่าน** ครูที่ถูกแก้ชื่อในเว็บใหม่เป็นสะกดต่างกัน ไม่ถูกสร้างซ้ำเมื่อกดดึงครูอีก (ยัง 143 คน) เพราะปุ่มเทียบเลขครูของโปรแกรมจัดตาราง ไม่ใช่ชื่อ |
| 10ฉ | คัดลอกวันแรกครบและทุกแถวถือเลขครูเดิม | **ผ่าน** ได้ 143 คน เท่ากับโปรแกรมจัดตาราง ทุกแถวถือเลขครูของโปรแกรมจัดตาราง ไม่มีแถวไหนว่าง และชุดรหัสประจำตัวตรงกันทุกตัว |

หมายเหตุ: ปุ่มดึงวิชา (ไม่มีในข้อสอบของสเปก) ลองแล้วในเครื่องพัฒนาเมื่อ 10 พ.ย. 2569: ได้ 271 วิชา เท่ากับโปรแกรมจัดตาราง ทุกแถวถือเลขวิชาของโปรแกรมจัดตาราง และกดซ้ำแล้วจอขึ้น "ไม่มีวิชาใหม่ให้ดึง (มีอยู่แล้ว 271 วิชา)" ไม่สร้างซ้ำ

ข้อควรระวังตอนพิมพ์เพิ่มครูหรือวิชาเอง ดูข้อ 3 และข้อ 4

### รอบอัตรากำลัง (ข้อ 1, 2, 7, 8, 9, 10 · ขั้นที่ 2)

ผลด้านล่างได้จากเซิร์ฟเวอร์จริงในเครื่องพัฒนา (ฐานข้อมูลทดลอง ครู 143 คน หลักสูตรตั้งต้นจากโปรแกรมจัดตาราง รอบ 2/2569 มี 1,220 แถว ตัวเลือกคาบเสรี 44 ตัว)
เมื่อ 16 พ.ย. 2569 (ค.ศ. 2026-11-16) · ส่วนที่ "ส่งเข้าโปรแกรมจัดตาราง" ของแต่ละข้อรอขั้นที่ 3

| ข้อ | เรื่อง | สถานะ |
|---|---|---|
| 1 | รหัสกลุ่มสาระเห็นแถวของกลุ่มอื่นไม่ได้ ทั้งบนหน้าจอและคำขอตรง | **ผ่าน** หัวหน้ากลุ่มสังคมศึกษาส่งคำขอขอแถวของกลุ่มภาษาไทยตรง ๆ ได้กลับมาแค่ 152 แถวของกลุ่มตัวเอง · ขอแก้แถวของกลุ่มภาษาไทยได้ 403 "รายการนี้เป็นของกลุ่มสาระอื่น…" · หน้าสรุปของหัวหน้ามีแค่ 20 วิชาของกลุ่มตัวเอง |
| 2 | หัวหน้ากลุ่มสาระแก้ช่องของแถววิชา (รหัส ชื่อ คาบ) ไม่ได้ แม้ส่งคำขอตรง | **ผ่าน** ส่งรหัสวิชาหรือคาบ/สัปดาห์มาที่แถว → 400 "ส่งช่อง code ไม่ได้ (รับเฉพาะ …)" · ขอแก้บรรทัดหลักสูตร → 403 · ค่าในแถวไม่เปลี่ยน |
| 7 | ยอดรวมคาบรายครูตรงกับชีต (ครูผู้สอน) ของไฟล์เดิม อย่างน้อยสองกลุ่มสาระ | **ต้องเทียบเอง** (ข้อ 15) · ที่ตรวจแล้ว: ครูที่สอน ส32103 2 ห้อง และ ส33102 7 ห้อง (2 คาบ) ได้จำนวนคาบ 4 และ 14 รวม 18 ตรงกับภาพชีตเดิมที่ส่งมา · ทุกกลุ่ม: รวมคาบสอนในหน้าสรุปเท่ากับยอดของเซิร์ฟเวอร์ครบ 139 คน |
