# เว็บลงอัตรากำลัง — สเปกการออกแบบ

วันที่ 6 พฤศจิกายน 2569 · สถานะ: รอการยืนยันจากผู้ใช้ · ยังไม่เริ่มเขียนโปรแกรม

---

## 1. ปัญหาที่แก้

ทุกเทอมต้องลอกอัตรากำลังด้วยมือสองรอบ — รอบหนึ่งลงในไฟล์ Excel 39 ชีต
(ชีต `(รายวิชา)` และ `(ครูผู้สอน)` ของแต่ละกลุ่มสาระ รวม 1,463 แถว) และอีกรอบลงในโปรแกรมจัดตารางสอน
ชีต `(ครูผู้สอน)` เองก็เป็นข้อมูลชุดเดียวกันมองจากฝั่งครู ซึ่งก็ลอกด้วยมืออีกต่อหนึ่ง

**เป้าหมาย:** กรอกครั้งเดียว แล้วส่งตรงเข้าโปรแกรมจัดตารางสอนได้

**ไม่ใช่เป้าหมาย:** จัดคาบแทนคน · แก้ตารางที่จัดเสร็จแล้ว · แทนที่โปรแกรมจัดตารางสอน

## 2. สถาปัตยกรรม

เว็บใหม่เป็นหน้าเว็บของตัวเองที่ repo แยก ได้ลิงก์คนละชุดจากเว็บตารางเรียน
แต่คุยกับ **เซิร์ฟเวอร์และฐานข้อมูลเดียวกัน**

```
เว็บลงอัตรากำลัง  ──┐
(repo ใหม่, ลิงก์ใหม่)│
                     ├──→  เซิร์ฟเวอร์ Render เดิม  ──→  ฐานข้อมูลเดิม
เว็บตารางเรียน    ──┘        (mock_api.py)
(repo เดิม, ลิงก์เดิม)
```

**ทำไมใช้เซิร์ฟเวอร์เดียวกัน** — การส่งเข้าโปรแกรมจึงเป็นการทำงานภายในฐานข้อมูลเดียวกัน
อ้างครูด้วยรหัสครู ไม่ใช่ชื่อ จึงไม่มีการจับคู่ชื่อเลย
(ชื่อครูในไฟล์ Excel บางชื่อตกตัวการันต์ เช่น "ชนะพันธ" ที่หายไป ์ — ถ้าจับคู่ด้วยชื่อจะเกิดครูซ้ำหรือจับผิดแน่นอน)

**งานตั้งค่าที่เกิดจากการแยก repo** (ครั้งเดียว)

1. ตั้งที่อยู่เซิร์ฟเวอร์ใน repo ใหม่ (`VITE_API_URL` เป็น repo secret เหมือน repo เดิม)
2. เพิ่มที่อยู่เว็บใหม่เข้ารายการต้นทางที่เซิร์ฟเวอร์ยอมรับ (CORS) ไม่งั้นเบราว์เซอร์จะบล็อกทุกคำขอ
3. workflow deploy ของ repo ใหม่ (คัดลอกจาก repo เดิมได้)

## 3. ใครล็อกอิน และเห็นอะไร

### admin (รหัสเดียว)

- เห็นทุกกลุ่มสาระ
- **หน้าที่หลัก: สร้างแถววิชาให้ทุกกลุ่มสาระ** — รหัสวิชา ชื่อวิชา ชั้น ห้องเรียน คาบ/สัปดาห์ หน่วยกิต ประเภทวิชา
- เปิด/ปิดรอบ · ตรวจผ่าน · ตีกลับให้แก้ · ส่งเข้าโปรแกรม
- ตั้ง/เปลี่ยน/ปิด รหัสเข้าของทุกกลุ่มสาระ

### หัวหน้ากลุ่มสาระ (กลุ่มสาระละหนึ่งรหัส, 11 กลุ่ม)

- เห็นแค่แถวของกลุ่มตัวเอง
- **หน้าที่หลัก: ใส่ชื่อครูในแต่ละวิชา** — ครูผู้สอน · ครูสอนร่วม · ห้องปฏิบัติการ · คาบคู่ · หมายเหตุ
- แก้ช่องของแถววิชา (รหัส ชื่อ คาบ ชั้น ห้อง) **ไม่ได้** — ถ้าผิดต้องแจ้ง admin
- กดส่งกลุ่มตัวเองเมื่อครบ
- ดูสรุปจำนวนคาบรายครูของกลุ่มตัวเอง

### รหัสเข้า

- ไม่มีชื่อผู้ใช้ มีแต่รหัส — หน้าแรกคือช่องกรอกรหัสช่องเดียว ระบบรู้เองว่าเป็น admin หรือกลุ่มไหน
- เก็บแบบแฮช อ่านย้อนกลับไม่ได้ ไม่มีฟังก์ชัน "ขอดูรหัส" — ลืมแล้ว admin ตั้งใหม่
- admin ปิดรหัสของกลุ่มได้เมื่อเปลี่ยนหัวหน้ากลุ่มสาระ
- ปุ่ม **ส่งเข้าโปรแกรม** ต้องกรอกรหัส admin ซ้ำอีกครั้งตอนกด เพราะเป็นงานเดียวที่แตะข้อมูลจริงของโปรแกรมจัดตาราง

> **ข้อควรระวังที่แจ้งผู้ใช้แล้ว:** โปรแกรมจัดตารางสอนทุกวันนี้ยังไม่มีระบบล็อกอินเลย
> รหัสบนเว็บใหม่จึงป้องกันได้แค่เว็บใหม่ ใครที่รู้ลิงก์เว็บตารางเรียนยังเข้าไปแก้ตารางได้เหมือนเดิม
> การใส่ล็อกอินให้โปรแกรมจัดตารางเป็นงานแยก ยังไม่อยู่ในสเปกนี้

## 4. ข้อมูลที่เก็บ

### หลักการข้อเดียว

> **อัตรากำลังที่กรอก ต้องเป็นคนละก้อนกับแผนที่ตารางใช้อยู่**

ถ้าเว็บใหม่เขียนทับแผนการสอนเดิมโดยตรง ตารางที่จัดเสร็จแล้วจะถูกกระทบทันทีที่ใครกดบันทึก
เก็บแยกแล้วค่อยเทียบกัน ทำให้ "บอกว่าอะไรเปลี่ยน แล้วเลือกทีละข้อ" เป็นไปได้จริง
และทำให้ย้อนดูได้ว่าเทอมที่แล้วใครสอนอะไร

## 5. การเสนอแถวจากหลักสูตร

ตอน admin เปิดรอบใหม่ ระบบไล่หลักสูตรของทุกห้องแล้วเสนอแถวให้ครบ
พร้อมคาบ/สัปดาห์และกลุ่มสาระที่หลักสูตรระบุไว้

admin เลือกได้ว่าจะ รับทั้งหมด · แก้คาบ · เพิ่มวิชาที่หลักสูตรไม่มี · ลบแถวที่เทอมนี้ไม่เปิด

## 6. งานเดินจากขั้นไหนไปขั้นไหน

แต่ละกลุ่มสาระเดินของตัวเอง ไม่ต้องรอให้ครบทุกกลุ่มจึงตรวจได้

| ขั้น | สถานะ | ใครทำ | แก้แถวได้แค่ไหน | ขั้นถัดไป |
|---|---|---|---|---|
| 1 | เปิดรอบ + ระบบเสนอแถว | admin | ยังไม่สร้างจนกดยืนยัน | ตรวจแถวที่เสนอ |
| 2 | กำลังกรอกแถววิชา | admin | แก้/เพิ่ม/ลบ ได้ทุกกลุ่ม | เปิดให้กลุ่มสาระกรอก |
| 3 | กำลังกรอกชื่อครู | หัวหน้ากลุ่มสาระ | แก้ได้แค่ช่องครู/ห้องปฏิบัติการ/คาบคู่/หมายเหตุ ของกลุ่มตัวเอง | กดส่ง |
| 4 | ส่งแล้ว | หัวหน้ากลุ่มสาระ | ล็อก (ขอ admin ปลดล็อกได้) | admin ตรวจ |
| 5 | ตีกลับให้แก้ | admin | กลุ่มสาระแก้ได้อีก พร้อมหมายเหตุ | กลับขั้น 3 |
| 6 | ตรวจผ่าน | admin | admin แก้ได้ | กดส่งเข้าโปรแกรม |
| 7 | ส่งเข้าโปรแกรมแล้ว | admin | ล็อกถาวร เก็บเป็นประวัติ | จบรอบ |

## 7. การส่งเข้าโปรแกรมจัดตารางสอน

### กฎเหล็ก

> **การส่งเข้าโปรแกรมเขียนแค่แผนการสอน ไม่แตะคาบที่ลงในตารางแล้วแม้แต่คาบเดียว**

ข้อนี้ผู้ใช้ยืนยันเอง และตรงกับข้อกำหนดเดิมของโปรแกรมที่ว่าเครื่องจัดตารางเสนอได้แต่ไม่เขียนคาบเอง

### รอบแรก (ตารางยังว่าง)

สร้างแผนการสอนให้ครบทุกแถว คาบยังไม่ลง แล้วไปจัดคาบในโปรแกรมเดิมตามปกติ

### รอบที่สอง (ตารางจัดไปแล้ว แต่อัตรากำลังเปลี่ยน)

ระบบไม่เขียนอะไรจนกดยอมรับ แต่แสดงหน้าเทียบก่อน แยกเป็น 4 กอง

| กอง | หมายถึง | กระทบคาบที่ลงแล้วไหม | กดให้แก้แล้วเกิดอะไร |
|---|---|---|---|
| **แถวใหม่** | วิชาที่รอบก่อนไม่มี | ไม่กระทบ | เพิ่มแผนใหม่ คาบยังไม่ลง |
| **คาบเปลี่ยนจำนวน** | เช่น 3 → 4 คาบ/สัปดาห์ | กระทบ | แก้จำนวนคาบในแผน · คาบที่ลงแล้วคงเดิมทั้งหมด |
| **เปลี่ยนครู** | ครูคนเดิมออก คนใหม่เข้า | กระทบ | แก้ชื่อครูในแผน · คาบที่ลงแล้วยังเป็นครูคนเดิม |
| **แถวที่หายไป** | เทอมนี้ไม่เปิดแล้ว | กระทบ | ลบแผน · คาบที่ลงแล้วคงอยู่ ติดป้าย "เกินแผน" |

แต่ละข้อมีปุ่ม **ให้แก้** / **ไม่แก้** ของตัวเอง กดแค่ข้อที่ต้องการ ที่ไม่กดก็คงเดิมไว้

**คาบที่ไม่มีแผนรองรับ** — เมื่อลบแผนแล้วคาบยังอยู่ โปรแกรมจัดตารางจะขึ้นป้าย "เกินแผน" ที่คาบนั้น
ไม่ลบให้ และไม่ถือเป็นข้อผิดพลาดที่ขัดการบันทึก — คนเป็นผู้ตัดสินใจว่าจะลบหรือเก็บไว้

### รายการงานที่ต้องไปทำเอง

หลังกดส่ง ระบบสร้างรายการว่าต้องไปจัดการคาบอะไร เช่น
"ท21101 ม.1/1 แผนเป็น 4 คาบ ลงไว้ 3 คาบ — ขาด 1 คาบ" หรือ
"ค21101 ม.2/3 เปลี่ยนครูในแผนเป็นครู ข แต่ 3 คาบที่ลงไว้ยังเป็นครู ก"

**รายการนี้ขึ้นในโปรแกรมจัดตารางสอน ไม่ใช่เว็บใหม่** เพราะที่นั่นคือที่ที่ไปแก้คาบ

### ประวัติ

เก็บว่าใครกดส่งเข้าโปรแกรมเมื่อไหร่ และข้อไหนถูกยอมรับ/ปฏิเสธ เพื่อย้อนดูได้ว่าแผนเปลี่ยนเพราะอะไร

## 8. ผลพลอยได้: ชีต (ครูผู้สอน) ไม่ต้องลอกอีก

ชีต `(ครูผู้สอน)` ของไฟล์เดิมเป็นข้อมูลชุดเดียวกันมองจากฝั่งครู พร้อมยอดรวมคาบ
เมื่อข้อมูลอยู่ในระบบแล้ว ระบบคำนวณและรวมคาบให้สด จึงไม่ต้องลอก และไม่หลุดจากกัน

หัวหน้ากลุ่มสาระเห็นของกลุ่มตัวเอง · admin เห็นทุกกลุ่ม

---

## 9. ของที่ไม่ทำในรอบนี้

- ล็อกอินให้โปรแกรมจัดตารางสอน (งานแยก)
- นำเข้าไฟล์ Excel อัตรากำลังเดิมโดยตรง — ชื่อครูในไฟล์ตกตัวการันต์หลายชื่อ
  การเลือกจากทะเบียนครูเร็วกว่าและไม่ผิด
- จัดคาบแทนคน หรือแก้ตารางให้ตามอัตรากำลัง
- แก้ไขทะเบียนครู/ห้อง/วิชา จากเว็บใหม่ (ทำในโปรแกรมเดิม)

---

## 10. สิ่งที่ต้องทดสอบก่อนปล่อยใช้

1. รหัสกลุ่มสาระเห็นแถวของกลุ่มอื่นไม่ได้ — ทั้งบนหน้าจอและจากคำขอตรงไปที่เซิร์ฟเวอร์
2. หัวหน้ากลุ่มสาระแก้ช่องของแถววิชา (รหัส ชื่อ คาบ) ไม่ได้ แม้ส่งคำขอตรง
3. ส่งเข้าโปรแกรมแล้ว **จำนวนคาบที่ลงในตารางไม่เปลี่ยนแม้แต่คาบเดียว** ทั้งสามกองที่กระทบ
4. เทียบรอบที่สองตรวจจับได้ครบทั้ง 4 กอง และกด "ไม่แก้" แล้วไม่เขียนอะไรเลยจริง
5. วิชาที่ยังไม่ผูกทะเบียน ส่งเข้าโปรแกรมแล้วสร้างวิชาใหม่ถูกต้อง และไม่สร้างซ้ำถ้ากดสองครั้ง
6. CORS: เว็บใหม่เรียกเซิร์ฟเวอร์ได้ และต้นทางที่ไม่ได้อนุญาตเรียกไม่ได้
7. ยอดรวมคาบรายครูตรงกับชีต `(ครูผู้สอน)` ของไฟล์เดิม อย่างน้อยสองกลุ่มสาระ
