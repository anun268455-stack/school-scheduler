## 1. เจตนา

ผู้ใช้ทำตารางสอนเทอมนี้เสร็จแล้ว ขั้นที่ 1 (ล็อกอิน ทะเบียนครู/วิชา รหัสเข้า) ขึ้นเว็บแล้ว 16 พ.ย.
หัวหน้ากลุ่มสาระที่ล็อกอินเข้ามาตอนนี้เห็นแค่ "ยังไม่มีรอบอัตรากำลังที่เปิดอยู่"

ผู้ใช้สั่ง: **"ทำขั้นที่ 2 เลย เพิ่มเติมคือช่วยตกแต่งให้สวยงามดูสบายตาด้วย"**

เป้าหมายเดิมของสเปกหลัก (ส่วนที่ 1): **กรอกอัตรากำลังครั้งเดียว** แทนการลอกด้วยมือสองรอบ
(ลงไฟล์ Excel 39 ชีต แล้วลงโปรแกรมจัดตารางสอนอีกรอบ) ขั้นที่ 2 คือส่วนที่ทำให้การกรอกนั้นเกิดขึ้นได้จริงบนเว็บ
ขั้นที่ 3 (ส่งเข้าโปรแกรมจัดตาราง) จะใช้ผลของขั้นนี้

## 2. ขอบเขต

**ทำในขั้นนี้**

1. รอบอัตรากำลัง — admin เปิดรอบของภาคเรียน ระบบเสนอแถววิชาให้ทุกห้อง ดูก่อนยืนยัน (สเปกหลักส่วนที่ 4–5 ปรับตามข้อ 4.1)
2. แถววิชา — admin แก้/เพิ่ม/ลบแถวได้ · หัวหน้ากลุ่มสาระแก้ได้แค่ช่องของหัวหน้า (สเปกหลักส่วนที่ 3–4)
3. คาบเสรี — ชุดคาบเสรีและตัวเลือก ตัวเลือกไปโผล่ในหน้ากลุ่มที่รับผิดชอบ (สเปกหลักส่วนที่ 4 "วิชาเสรี")
4. งานส่ง-ตรวจ-ตีกลับ รายกลุ่มสาระ (สเปกหลักส่วนที่ 6)
5. สรุปคาบรายครู แทนชีต (ครูผู้สอน) — สดจากแถวของรอบ พิมพ์จากเบราว์เซอร์ได้ (สเปกหลักส่วนที่ 9)
6. **หน้าตาใหม่ทั้งเว็บ** — ทุกหน้าของ `workload/` รวมหน้าที่มีอยู่แล้วของขั้นที่ 1 (ข้อ 6)

**ไม่ทำในขั้นนี้ (ขั้นที่ 3)** — ปุ่มส่งเข้าโปรแกรมจัดตาราง · ซิงก์ครู/วิชาเข้าโปรแกรม · หน้าเทียบ 4 กอง ·
สถานะรอบ "ส่งเข้าโปรแกรมแล้ว" · ปุ่มสร้างเทอมใหม่รับอัตรากำลัง

**ไม่ทำเลย** (เหมือนสเปกหลักส่วนที่ 10) — นำเข้า Excel เดิม · แก้ทะเบียนห้อง/ชั้น/กลุ่มสาระ/หลักสูตรจากเว็บนี้ · จัดคาบ

## 3. ข้อห้าม (ถ้าเกิดขึ้น ถือว่าล้มเหลวแม้ทุกอย่างอื่นทำงาน)

- **เขียนข้อมูลของโปรแกรมจัดตารางแม้แต่ไบต์เดียว** — `SLOTS` `REQUIREMENTS` `TEACHERS` `SUBJECTS`
  `ELECTIVE_POOLS` `ROOMS` `GROUPS` `DEPARTMENTS` อ่านอย่างเดียว ไม่แก้ dict ในลิสต์ด้วย
  (route ใต้ `/api/workload/` ข้ามตัวนับรุ่น การเซฟสแนปช็อต และด่านเทอมปิด — ดูคอมเมนต์ที่ `WORKLOAD_PREFIX`)
- **หัวหน้ากลุ่มสาระเห็นหรือแก้แถวของกลุ่มอื่นได้** ไม่ว่าทางหน้าจอหรือส่งคำขอตรง (สเปกหลักข้อทดสอบ 1–2)
- **แถวที่ครูมาจากเทอมก่อนถูกนับว่ายืนยันแล้วโดยไม่มีคนกด** — ป้าย "ยังไม่ยืนยัน" ต้องหายเพราะคนกดเท่านั้น
- ข้อผูกมัดของขั้นที่ 1 ยังมีผลทุกข้อ: ข้อความไทยทุกข้อความ · ไม่เพิ่ม dependency ฝั่งเซิร์ฟเวอร์ · อ้างครู/วิชาด้วยรหัส
  ไม่ใช่ชื่อ · ไม่มี endpoint ลบครูหรือวิชา · ไม่มีรหัสจริงใน log

## 4. สิ่งที่ผู้ใช้ตัดสินแล้ว และที่ต่างจากสเปกหลัก

### 4.1 แถวที่เสนอมาจากแผนการสอนของเทอมที่เพิ่งจัดเสร็จ พร้อมครูคนเดิม (ผู้ใช้เลือก "ข.")

สเปกหลักส่วนที่ 5 ให้เสนอแถวจากหลักสูตร (ได้วิชาและคาบ ช่องครูว่าง) ผู้ใช้เลือกให้เสนอจาก **แผนการสอนของโปรแกรมจัดตาราง**
(`REQUIREMENTS` — 1,220 แถวในข้อมูลตั้งต้น) ซึ่งมีครูอยู่แล้ว หัวหน้ากลุ่มจึงแก้เฉพาะคนที่เปลี่ยน

ราคาที่ผู้ใช้ยอมรับ และวิธีจ่าย:
- ทุกแถวที่ครูมาจากแผนเดิมติดสถานะ **"จากเทอมก่อน · ยังไม่ยืนยัน"** หัวหน้ากลุ่มต้องกดยืนยัน (ทีละแถว หรือเลือกหลายแถวแล้วยืนยันพร้อมกัน)
- **กลุ่มกดส่งไม่ได้จนกว่าทุกแถวของกลุ่มจะยืนยันแล้วและมีครูผู้สอน**
- เปลี่ยนครูในแถวใด = แถวนั้นนับว่ายืนยันแล้วในการกระทำเดียวกัน (คนเลือกเองแล้ว)
- ถ้าเทอมใหม่วิชาเปลี่ยนรหัส (ท21101 → ท21102) admin แก้รหัสในแถว — ข้อนี้ต้องทำเหมือนกันแม้เสนอจากหลักสูตร
  เพราะหลักสูตรในโปรแกรมก็ได้มาจากแผนของเทอมนี้

### 4.2 คำตัดสินของผู้เขียนแบบ (ผู้ใช้ให้ผมตัดสินเรื่องวิธี — แก้ได้)

|---|---|---|

| ครูสอนร่วม | แผนเดิมเก็บเป็นสองแถวที่อ้างกันเอง (กฎเดียวกับ `coTeachHalves` ใน `frontend/src/utils/teachingLoad.ts`) → รวมเป็น **แถวเดียว ช่องครูสอนร่วม** | สเปกหลักให้แถวมีช่องครูสอนร่วม |
| คาบเสรี | `ELECTIVE_POOLS` (13 ชุด) → ชุดคาบเสรีของรอบ ตัวเลือกมีครูเดิมใส่ไว้ + "ยังไม่ยืนยัน" · กลุ่มที่รับผิดชอบตัวเลือก = กลุ่มสาระของวิชานั้น | สเปกหลักส่วนที่ 4 |
| อ้างครูและวิชา | แถวอ้าง **`wl_teachers.id` / `wl_subjects.id`** ของเว็บนี้ ไม่ใช่รหัสของโปรแกรมจัดตาราง · การเปิดรอบดึงครูและวิชาจากโปรแกรมให้ก่อนทุกครั้ง (ตัวเดียวกับปุ่มดึง — ไม่สร้างซ้ำ) แล้วแปลงรหัสฝั่งตารางเป็นรหัสของเว็บนี้ผ่าน `sched_id` | ทะเบียนเป็นของเว็บนี้ (สเปกหลักแก้ไข 8 พ.ย.) · ห้ามจับคู่ด้วยชื่อ |
| ห้องเรียน · ห้องปฏิบัติการ | อ้างรหัสของโปรแกรมจัดตารางตรง ๆ (ทะเบียนที่ยืมอ่าน สเปกหลักส่วนที่ 4) · ห้องย่อย (ม.4/6ก) เป็นห้องเรียนได้ | ไม่มีทะเบียนของเว็บนี้ |

### 4.3 ขั้นของงาน

**สถานะรอบ:** `เตรียม` (admin คนเดียวเห็น แก้แถวได้ทั้งหมด) → `เปิดให้กรอก` → `ปิดรอบ` (อ่านอย่างเดียว เก็บดูย้อนหลัง)
ปุ่ม "เปิดให้กลุ่มสาระกรอก" ทำได้เมื่อกอง "ยังไม่ระบุกลุ่มสาระ" ว่าง · ปิดรอบได้ทุกเมื่อ (ต้องพิมพ์ชื่อรอบยืนยัน)

**สถานะรายกลุ่มสาระ** (สเปกหลักส่วนที่ 6): `กำลังกรอก` → `ส่งแล้ว` → `ตรวจผ่าน` หรือ `ตีกลับ` (มีหมายเหตุ) → `กำลังกรอก` อีกรอบ
- หัวหน้าแก้ได้เมื่อกลุ่มเป็น `กำลังกรอก` หรือ `ตีกลับ` และรอบเป็น `เปิดให้กรอก`
- `ส่งแล้ว` ล็อกหัวหน้า · admin ตีกลับได้ (= ปลดล็อก) · `ตรวจผ่าน` admin ยังแก้ได้ (สเปกหลัก ขั้น 6)
- admin แก้แถวของกลุ่มที่ `ส่งแล้ว` หรือ `ตรวจผ่าน` ได้ · การแก้ของ admin ไม่เปลี่ยนสถานะกลุ่ม
- บันทึกว่าใครส่ง/ตรวจ/ตีกลับเมื่อไหร่ ("ใคร" = ชื่อเรียกของรหัสที่ใช้)

**ช่องที่แต่ละฝ่ายแก้ได้**

| ช่องของแถว | admin | หัวหน้ากลุ่ม (กลุ่มตัวเอง) |
|---|---|---|
| ห้องเรียน · วิชา (รหัส/ชื่อ) · หน่วยกิต · คาบ/สัปดาห์ · ประเภท · กลุ่มสาระ | ✓ | ✗ |
| ครูผู้สอน · ครูสอนร่วม · ห้องปฏิบัติการ · คาบคู่ · หมายเหตุ · ยืนยัน | ✓ | ✓ |
| เพิ่ม/ลบแถว | ✓ (เตรียม/เปิดให้กรอก) | ✗ |

คาบเสรี: ชุด (ชื่อ ห้องที่ใช้ คาบ/สัปดาห์) admin เท่านั้น · ตัวเลือก (วิชา กลุ่มที่รับผิดชอบ) admin · ครู ห้อง หมายเหตุ ยืนยัน ของตัวเลือก
หัวหน้ากลุ่มที่รับผิดชอบ · หัวหน้าเห็นแค่ตัวเลือกของกลุ่มตัวเอง (สเปกหลักข้อทดสอบ 9)

- **สี** (โทเค็นใน `:root` ของภาพตัวอย่าง): พื้นหลังสีกระดาษอุ่น `#f6f3ec` · การ์ดขาว เส้นขอบอุ่นอ่อน `#e8e2d6` ·
  ตัวอักษร `#2b2a26` รอง `#736d62` · สีหลักเขียวหัวเป็ดเข้ม `#1f6f6b` ·
  ชิปสถานะพื้นอ่อน: รอ/ยังไม่ยืนยัน `#fff3d4`/`#8a5a00` · ผ่าน/ยืนยัน `#e4f3e8`/`#1e6b34` · ส่งแล้ว `#e8eefb`/`#2d4f9c` · ตีกลับ/ผิดพลาด `#fbe8e4`/`#a3352b` ·
  แดงใช้กับข้อผิดพลาดและตีกลับเท่านั้น
- **ตัวอักษร**: Sarabun (มีอยู่แล้ว) ขนาดพื้น 16px บรรทัด 1.6 · หัวข้อหน้า 26px หนา · ตัวเลขสรุป 28px
- **ชิ้นส่วน**: การ์ดมุมโค้ง 14px · ปุ่มหลัก/รอง/โปร่ง · ชิปสถานะมีจุดสี · แถบความคืบหน้า · ตัวเลือกแบบปุ่มติดกัน (ทั้งหมด/ยังไม่ยืนยัน/ยืนยันแล้ว) ·
  แถวที่ยังไม่ยืนยันพื้นเหลืองจางมาก · ตารางเส้นแบ่งบาง ไม่มีเส้นตั้ง
- **โครงหน้า**: แถบบนขาว (โลโก้ · ชิปรอบปัจจุบัน · ใคร · ออกจากระบบ) · แท็บเมนูของ admin
  (รอบอัตรากำลัง · สรุปคาบรายครู · ทะเบียนครู · ทะเบียนวิชา · รหัสเข้า) · เนื้อหากว้างสุด ~1240px
- **ทุกหน้าของขั้นที่ 1 ใช้ชุดเดียวกัน** (ล็อกอิน ตั้งรหัสครั้งแรก ทะเบียน รหัสเข้า) — ไม่ใช่แค่หน้าใหม่
- ใช้ได้บนจอเล็ก (หัวหน้าบางคนจะเปิดจากโทรศัพท์): ตารางแถวกลายเป็นการ์ดซ้อนเมื่อจอแคบ
- หน้าสรุปคาบรายครูมี print stylesheet (พิมพ์จากเบราว์เซอร์ได้ ไม่มีแถบเมนูติดไป)
- ข้อความว่าง/กำลังโหลด/ผิดพลาดทุกที่มีภาษาไทยที่บอกว่าต้องทำอะไรต่อ

## 7. ข้อทดสอบก่อนปล่อย (เพิ่มจากสเปกหลักส่วนที่ 11)

- สเปกหลักข้อ 1, 2, 8 (ครึ่งที่นับคาบ), 9, 10 ผ่าน · ข้อ 7 (ยอดรวมตรงกับไฟล์ Excel เดิม) ต้องให้ผู้ใช้เทียบเอง เพราะไม่มีไฟล์นั้นใน repo
- เปิดรอบจากข้อมูลตั้งต้น: ได้แถวเท่ากับ `REQUIREMENTS` ลบครึ่งหลังของคู่สอนร่วม · คาบเสรีครบ 13 ชุด · ทุกแถว "ยังไม่ยืนยัน"
- ยอดคาบรายครูของรอบที่เพิ่งเปิด (ยังไม่มีใครแก้) **เท่ากับ** ยอดที่โปรแกรมจัดตารางคำนวณจากแผนเดิมทุกคน
- หัวหน้ากลุ่ม ก ส่งคำขอตรงแก้แถวของกลุ่ม ข / แก้ช่องของ admin / แก้ตอนส่งแล้ว → ถูกปฏิเสธทั้งหมด
- ระหว่างทั้งหมดนี้ `revision` ของเว็บตารางไม่ขยับ และข้อมูลของโปรแกรมจัดตาราง (GET ทุกทะเบียน + แผน + คาบ) เหมือนเดิมทุกไบต์
